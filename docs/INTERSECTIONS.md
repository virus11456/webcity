# 路口控制（M2-05）

MS2 解鎖道路工具的「路口管理」。點選三分支以上的路口，選擇無號誌、紅綠燈或停止標誌，可勾選禁止左轉，再按「套用路口設定」。桌機與觸控均需明確套用，不收費。雙指鏡頭手勢及取消不會送出設定。

Worker 驗證解鎖與節點存在，再以 roadsChanged 同步。節點的可選 `manualControl` 保護玩家設定，不會被後續拓路、拆路或升級的自動號誌規則覆蓋。`banLeft` 記錄路口全部進入方向的左轉限制，供 M2-06 車道連接採用。舊存檔缺省為自動控制、允許左轉。

原有圓角路口保留，增加斑馬線與進入車道停止線；高速公路不設斑馬線。紅綠燈、燈桿與停止標誌均為原創程序幾何。靜態路口設施共用一個 mesh，燈號用 InstancedMesh，只在相位改變時更新顏色。對向進入方向分組，每組綠燈 12 模擬秒；時間取自 Worker 固定 tick，暫停時不前進，和財政日曆、日夜視覺週期分開。此卡未實作車流，遵守燈號的車輛在後續交通任務接入。

驗證涵蓋 Worker 真實指令入口、MS2 解鎖、手動設定保留、路網變更、存讀檔、對向分組與燈色切換，以及三裝置選取、套用後重新選取的真實 UI 操作。手機使用 Chromium 觸控模擬，另檢查橫式；未以實體 iOS Safari 驗證。
