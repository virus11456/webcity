# M1-05：可操作的直線道路工具

首頁按「開始鋪路」進入建造地形。展示街區沒有模擬實體，因此建造時隱藏展示建築與道路；「展示街區」可切回展示，再按「開始鋪路」仍保留本次工作階段的道路與資金。重新整理會重建新城市，目前尚無存檔，面板有明確提示。

## 操作

- 桌機：點起點，移動游標看藍／紅預覽，再點終點建造。完成後終點成為下一段起點，可連續鋪設。也可按確認按鈕。
- 手機／平板：點起點，再點終點，檢查長度、造價、坡度及原因，按「✔ 確認建造」。確認前再點地面可改終點；拖曳不會誤建造。
- 「✕ 取消路段」、Esc 或右鍵取消未完成路段；雙指操作取消草稿並控制鏡頭。「探索城市」恢復單指／左鍵拖曳鏡頭。右鍵、滾輪及 WASD／QE／RF 鏡頭操作繼續可用。
- 道路種類與角度吸附開關在面板設定；Shift 暫時關閉角度吸附。普通模式目前只有開局解鎖的小路、單行小路、碎石路，其他選項列出但不可選。
- 暫停仍可建造。確認期間鎖住重複送出，收到成功回覆才接續下一段；取消或切換工具不會被晚到的回覆重新開啟草稿。

## 權威與訊息

`CommandDispatcher` 先檢查不可信的 buildRoad 載荷：道路種類、有限座標、直線三等分控制點、elevated=false。`Simulation.buildRoad` 使用共用 world 驗證函式檢查幾何、土地、水域、坡度、建築、解鎖、資金；不接受客戶端造價。成功一次套用道路變更、更新全域 nextId 與資金，再送 roadsChanged、fundsChanged、result。失敗不扣款、不配置 ID、不送道路變更。

`fundsChanged` 立即更新鏡像 money / stats.money，不插入每日 statsHistory。WorldMirror 從新增節點／路段更新 nextId，避免接續預覽重用既有 ID。道路事件與地圖更新才複製建造所需鏡像，游標移動不複製整個 WorldSnapshot。工作執行緒逾時／失敗後停止確認，不自動重送可能已扣款的命令。

沙盒模式由既有 GAME_MODES 規則免扣款、解鎖全部路型；目前首頁仍以普通模式啟動，新遊戲模式選單屬後續任務。

## 地面道路整合

送出的 RoadDraft 是已定位座標。Worker 使用 exact 接點模式：只以浮點容差重用同點接點，不再次進行 8 m、15° 或長度取整，避免預覽與扣款位置不同。

地面道路沿地形表面，不能將兩端高度線性內插的微小差值誤當成不同高架層。RoadGraph.previewRoad 增加可選地表高度函式：只對兩條非 elevated 路段使用共同地表連接／重疊規則，路口高度取實際地表。一般 M1-03 圖操作省略此函式時保留原本高度分離規則。M1-04 地面預覽與 Worker 都使用這個地表模式，接在路段內部的高度取地表；獨立 snapRoadPoint 的預設高度內插 API 保留。

新建道路先使用貼地柏油色帶提供已建位置回饋；藍色幽靈代表可以建，紅色代表拒絕。色板沿用 ART，表面提升 0.25 m、預覽提升 0.5 m、4 m 網格細分均集中在 data/roadTool.ts，沒有每幀重建。完整人行道、路緣、標線、路口多邊形、地形平整及道路 Chunk 合併仍屬 M1-06；此卡不宣稱通過 1,000 路段 draw-call 預算。

## 驗證

單元測試覆蓋：暫停建造、精確扣款、資金剛好／不足、未解鎖、沙盒、真實非平面地形十字與 T 接點、鏡像 ID／資金、非法／曲線／高架載荷、重複確認鎖、拒絕回覆、逾時不重送、取消後晚到回覆、觸控確認、滑鼠點擊、拖曳取消、Shift 與工具切換。

Playwright 使用真實 Pointer Events 及 CDP touch：三裝置實際鋪路、連續道路與十字切割、扣款、非法土地紅色預覽、Esc／右鍵／雙指取消、雙指鏡頭、展示切換保留工作階段、按鈕尺寸；另檢查手機橫式。截圖位於 docs/screenshots/m1-05/。這些是裝置模擬，未宣稱實機測試。

M1-06 更新：已建道路改用人行道、路緣、標線與圓角路口的合批 Mesh；Worker 同步地形整平。藍／紅工具預覽仍為輕量色帶。詳見 `docs/ROAD_MESH.md`。
