# 城市物件資訊（M1-22）

在「探索城市」模式點擊玩家建造的道路或建築，Worker 回傳一份唯讀資料，地面以強調色高亮。桌機／平板右側顯示資訊；手機使用 BottomSheet。桌機點空地、Esc、關閉按鈕或切換工具清除選取；手機關閉面板後可再次點選地圖。拖曳與雙指手勢仍由相機控制，不因資訊功能改成放置手勢。

面板呈現地址、道路長度、建築狀態／等級／入住容量／人口／就業容量、水電污水、問題與實付建造費。街名與門牌由物件 ID 穩定選取，因此日後存讀檔保持一致；這不是實際地理地址。未實作的污染、交通與個人通勤不偽造數值。

`InspectTool` 快取拓樸命中資料，透過 `inspect` 指令取得單一物件；收到建築／道路事件更新資料，被刪除即關閉。請求世代避免較晚的回覆重開已關閉面板。Worker 回傳複本，不提供修改物件的 UI。

共用 Panel／BottomSheet 使用直接標籤，避免多個 Preact root 的 `useId` 重複導致手機對話框被城市詳情誤命名。
