# M1-10 程序生成建築與施工動畫預覽

## 查看與操作

城市首頁的「建築工坊」連到 `?gallery=1`。預設展示六種分區；「全部款式」可逐頁瀏覽 164 種合法分區 × 等級 × 占地組合，也可依分區、等級與尺寸篩選。點建築放大，再次點擊或「返回總覽」回到列表。支持換外觀、左右旋轉及夜間燈光。

依本次追加需求，工坊提供「開工地基／蓋到一半／接近完工／完全蓋好」四個階段，以及連續進度滑桿、播放／暫停。播放為 12 秒的外觀預覽，切到背景或 WebGL context 遺失時不推進。這不是遊戲施工時計；城市的三遊戲天施工仍在 M1-12 接入 Worker。M1-11 將接上實際建築狀態與批次渲染。工坊不修改存檔、資金或城市世界。

## 模型與貼圖

`render/buildings/generator.ts` 的 `generateBuilding(zone, level, w, d, seed)` 回傳單一 `BufferGeometry`，包含頂點色、平面法線及 UV，原點為地塊正面中央，+Z 朝道路。所有數值輸入須為合法整數、符合分區的等級及占地範圍；不支援的組合明確拒絕。亂數只使用 `core/rng.ts`，相同輸入產生相同幾何／色彩／UV。相鄰整數 seed 會循環牆面色板；實際相鄰建築 seed 分配留給成長系統。

- RL：雙斜／四坡屋頂、門廊、寬地塊車庫、前院與後側小樹。
- RH：基座、塔身、陽台帶、女兒牆、設備箱，高等級增設水塔。
- CL：店面玻璃、彩色雨棚、招牌板與空調箱。
- CH：商場基座、退縮單／雙塔、招牌與設備。
- I：鋸齒廠房，二級以上紅白煙囪（20–40 m），三級儲槽與卸貨平台。
- O：三段退縮玻璃塔、深色屋頂平台與天線。

高度與樓層遵守 ART §3.1。ART 未指定 CL／I 的程序模型預算，本實作分別採 600／1,500 三角形；RL ≤600，其餘高密度 ≤1,500。這些是完成建築的預算，不包含施工鷹架與起重機。

`windowAtlas.ts` 用 Canvas 產生原創 1024×1024 色彩 Atlas 與對齊的自發光遮罩；六分區各四種窗型，保留空白 tile 給屋頂等純色表面。每層牆面 UV 對應一列窗型。顏色貼圖為 sRGB，遮罩為線性資料；固定 seed 決定亮窗。夜間按鈕僅預覽燈光，正式日夜循環屬 M3-06。

## 施工階段

`world/constructionVisual.ts` 是純進度映射，`ConstructionBuilding` 只接收呼叫方提供的 0–1 進度，不決定遊戲施工何時完成。零進度顯示地基；進度增加時逐步揭露按建築體量生成的柱與樓板，以及外側鷹架。大型建築增設會旋轉的起重機。後段逐步覆上完成外牆與屋頂，100% 撤去全部工地設施，顯示完整建築。`setProgress(progress, baseY)` 可調整地形上的裁切高度。

目前施工效果為視覺預覽，不包含實際施工車輛、工人、塵土粒子、住戶入住或每日通勤。現有展示街區車輛仍為停放模型；有工作目的地的市民與道路交通屬 M2-07～M2-11。

## 架構與資源

`main.ts` 依網址分流，原城市組裝程式移至 `game.ts`，工坊由 `gallery.ts` 組裝 UI 與 renderer；工坊不啟動 Sim Worker 或整張城市地形。兩路共用 PWA 註冊，打包後的延遲模組一併預快取。

工坊只使用一個 WebGL canvas，以 scissor 顯示最多六個視圖，每幀最多生成一棟。換頁釋放前頁幾何、材質與光源；所有款式共用一對 Atlas。動畫只更新裁切面與旋轉，不逐幀重建模型。相機、模型與日夜設定能在 context 恢復後重新上傳。UI 與 Three.js 分層，44px 控件、12px 文字與手機直／橫式布局均納入檢查。

## 驗證方法

單元測試遍歷 164 種合法組合、四個 seed，比對幾何 SHA-256、法線／色彩／UV 有限性、地塊邊界、樓層範圍與三角形上限；另驗證不同 seed、非法輸入、Atlas tile 邊界及四階段連續性。

Playwright 以桌機 Chromium 模擬 iPhone 15、iPad Pro 11 與 Desktop，驗證模型／四階段截圖、播放到完工、暫停、放大、旋轉、夜景、手機橫式、離線重載、回到城市及 164 款翻頁時的 GPU 資源穩定性。這不是 Safari／實機效能驗證，也未宣稱 5,000 棟城市渲染已完成。

提交驗證：lint、typecheck、524 項單元測試與 build 通過；完整三裝置 E2E 60 項通過、9 項不適用略過。最後的動畫狀態重用與 DOM 更新優化另重跑三裝置工坊流程。截圖見 `docs/screenshots/m1-10/`。
