# M1-13 人口與就業

住宅完工後，下一次日結開始每天最多搬入一戶，直到住宅容量填滿。商業、工業與辦公完工後提供職位，每日按教育條件與直線距離媒合。建造模式的獨立資訊列顯示人口、入住／容量、就業、失業、職缺與今日搬入／搬出，資訊列不增加下方建造面板高度。

## 容量與統計模型

`buildingCapacity` 依 GDD §5.3 的六分區、等級、占地表計算 `max(1, round(格數 × 每格容量))`。住宅 `households` 是可住戶數，實際入住在 `housing.occupied`；工作建築 `jobs` 是總職位、`workers` 是實際員工。施工中、荒廢、燒毀均為零容量；專用公共服務工作表尚未定義，此卡僅處理六分區建築。

住宅只保留五種戶量的戶數、四種教育／年齡層人數及就業群組，不建立個別市民。`citizens` 仍是空陣列。家庭人數為 1–5，抽樣權重 20／30／30／10／10%，期望值正好 2.6 人。

設計未指定 M1 移入人口的教育與年齡比例，因此採以下明確起始假設，集中在 `POPULATION_PROFILE`：教育 0／1／2／3 為 40／40／15／5%；兒童／青少年／成人／長者為 20／10／55／15%。以最大餘數法轉為整數，總和保持等於該棟居民數；平均教育由實際整數分布計算。全市可工作人數為 `floor(總居民 × 0.55)`，以最大餘數法依居民數分配到各住宅，再按該棟居民教育分布分配，不超過各教育人口；避免小住宅逐棟取整而少算勞動人口。這些是統計估計，學校、教育升級、年齡成長及出生死亡仍屬後續任務。

## 每日搬入與搬出

- 日結時每棟最多一戶，已填滿就停止。施工期間不能入住。沒有道路或待拆重分區的住宅停止新入住。
- 幸福度嚴格低於 30，每棟每天有 2% 機率搬走一個既有家庭；從現有戶量加權選取，移除整戶的人數。低幸福度期間停止新入住，不會同日補回搬走的家庭。
- 現階段採城市幸福度；尚未做單棟幸福度及水電服務計算，因此一般試玩初始 50 不會憑空出現幸福度下降。低幸福度機率與整戶搬出由單元測試驗證。
- 隨機源由世界 seed、建築 ID、遊戲日決定；`lastMigrationDay` 防止同日重複搬入。暫停不日結，倍速只改變同一時間線的推進速度。
- 拆屋、改分區拆除、荒廢、容量縮減會使居民離開；工作與人口立即重新整理。日內搬入／搬出計數保留至隔天，不受普通統計刷新重設。

## 就業規則

職位按 GDD 的分區／等級教育百分比，以最大餘數法配置；同額以教育索引決定。先處理低教育勞動者，再處理高教育者，住宅同教育群按 ID 排序。

每群人尋找最近且有合格空缺的工作建築，距離相同以較小 ID 優先。高教育可做低要求工作，反向禁止；同工作建築內先填最接近自身程度的空缺。填滿一家才續找下一家，每次都是整組人數移交，不逐人尋路。用 64m 空間桶索引可用職位，從近到遠擴大半徑；該教育可填的名額耗盡就移出索引，避免每個群組掃遍所有工作建築。住宅保留 `workplaceId / education / requiredEducation / workers` 群組，工作建築保留實際員工教育數。

每日重新媒合；失去住宅、工作建築或道路會立即移除相應關聯。無道路的職位可顯示空缺，但不能吸收員工。`employed ≤ availableWorkers` 且 `workers ≤ jobs`，所有分配都有教育資格與實際居民來源。M1 不驗證道路圖可達性或安排路徑；個別固定職務、出門、上班、回家及可見車人屬 M2。

## Worker、鏡像與日結

日結先處理斷路荒廢，再遷移與媒合，最後結算每日統計；施工完成、道路編輯及拆除可觸發不遷移的即時重新整理。數據只由 Worker 寫入，UI 使用鏡像防禦性複本。

`stats.transient` 表示即時狀態刷新：更新畫面統計但不追加每日歷史，避免一批完工或拆除在圖表中插入重複日期。日結保留原本一次一筆歷史。人口變更使用 `buildingsChanged` 部分更新，不含位置／尺寸，因此不會取消畫路、分區或拆除中的筆畫。

## 驗證

單元測試覆蓋六分區所有合法等級與占地、取整、戶量期望值、每日一戶上限、滿戶、低幸福度 2% 抽樣、暫停、確定性重播、距離／教育媒合、職缺與勞動者上限、拆除／荒廢立即清除就業、UI 鏡像隔離及每日歷史不受即時刷新污染。

Playwright 使用原生滑鼠／觸控，讓真實道路兩側住宅與商業完工、入住、就業，暫停後拆掉有人住的住宅，再清除商業分區並等待拆除，確認人口、搬出及失業數。手機另驗證橫式排版。裝置為 Chromium 模擬，非 iOS Safari 實機。

動態需求接續 M1-14；此版仍無存檔，重整會清除試建城市。

## 規模量測

Node 獨立人口系統測試：1,000 棟住宅、1,000 棟工作建築、100,000 居民、55,000 勞動者、64,000 職位，匹配 55,000 人且保留 9,000 職缺。暖機後五次計算約 11.35–20.96ms，中位 15.45ms；此數字只涵蓋人口／媒合，不包含整個 Worker tick、傳輸或 Three.js 渲染。大量場景另有不依賴計時的守恆測試。
