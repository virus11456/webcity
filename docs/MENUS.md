# 主選單與城市啟動

預設網址進入主選單，尚未啟動 WebGL 或模擬 Worker。新遊戲可選三種地圖、seed、城市名稱、一般／簡單／沙盒。繼續會載入 IndexedDB 中最新的手動或自動存檔；讀取可選個別槽。`?play=1` 保留空白城市的開發驗證入口。

暫停選單先取得 Worker 暫停確認再顯示，返回恢復之前的速度。儲存並回主選單先完成自動槽交易才導頁，失敗會留在城市。畫質與邊緣捲動立即套用，設定存在 localStorage；UI 字級為 90–130%，最小文字仍為 12px。音量是明確標示的停用佔位，音效屬 M3。iOS 非獨立模式會顯示 Safari 加入主畫面的說明。

新遊戲／讀檔以 sessionStorage 傳遞一次性請求，重新啟動遊戲，確保舊 Worker、GPU 資源與事件全部釋放。存檔仍留在原瀏覽器。多個 UI 根節點的標籤使用獨立的語意名稱，避免重複 id。

Playwright 覆蓋三種 viewport：選圖、命名、開始、暫停、設定、儲存退出、繼續；另驗手機橫式。這是 Chromium 裝置模擬，並非 Safari 實機驗證。
