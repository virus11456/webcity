# 公共設施與地標素材（M3-12）

提供 GDD／BUILDINGS 中 30 種建築各一個正式模型，另有 12 種原創地標，共 42 個 `svc_{id}.{hash}.glb`，合計 883,832 bytes。每檔包含 LOD0／1／2、Meshopt、同一組 1024×1024 KTX2 色彩／自發光 atlas。全部使用 ART 色板與 roughness 0.85／metalness 0；最大面數為 396／204／12 triangles。樹模型三段為 72／12／12。

設施包括風力、燃煤、燃油、太陽能、水壩、抽水站、水塔、排放口、污水處理廠、垃圾掩埋／焚化／回收、警察／消防大小設施、診所／醫院、三種學校、墓園／火葬場、四種公園、樹、公車車庫與地鐵站。墓園保留墓位、步道與禮堂；火葬場使用獨立煙囪；不同設施有對應辨識細節。

地標為市政廳、博物館、天文台、體育場、鐘樓、植物園、會展中心、歌劇院、科學中心、紀念塔、燈塔、觀景塔。12 種幾何均不同；M3-12 原先只交付素材與工坊預覽；解鎖、造價與效果現已於 M4-11 接入，見 UNIQUE_BUILDINGS.md。尚未開放的進階設施也不在這張美術卡擅自加入玩法。

`npm run assets:models -- services` 重建原創離線幾何與 atlas；來源、模型參數、面數、大小與 URL 放在 `assets-source/catalog/services-recipes.json`。沿用 M3-10 的參數化離線製作方式，非 Blender 手工或外部商業遊戲素材。GDD 未指定占地的素材採 4×4，水壩 12×4、地標 6×6；正式放置仍依 Worker 的權威地塊縮放，不修改平衡數值或存檔。

FacilityAssets 從既有 AssetLibrary 非同步讀取、請求去重並共用 civic atlas，為既有 PowerRenderer／WaterUtilityRenderer／ServiceRenderer 提供可獨立釋放的幾何副本。一般、停用、燒毀材質分離；夜窗、陰影與資訊圖層 hooks 保留。既有可建設施未下載時繼續顯示程序模型；成功後替換。服務模型回呼合併到下一幀重建，樹仍使用 InstancedMesh。水務保留現地高差支柱與外伸取排水管；風力機用獨立 Rotor 節點保留風速驅動的葉片動畫。

驗證包含完整清單、三段面數／原點、12 種獨立地標造型、所有 GLB hash／Meshopt／KTX2、共用 atlas、非同步去重、獨立幾何釋放與狀態材質隔離。Playwright 讀入明確的設施展示存檔，確認正式載入、風力葉片角度改變及三裝置素材工坊截圖；不把這個展示存檔稱為自然發展城市。裝置驗證為本機 Chrome viewport 模擬，非 iOS 實機。

水電操作測試原先等待新屋自然成長入住，已不符合 M2 的日常時間尺度，會在進入供電驗證前逾時。現以明確的六位居民、無水電住宅存檔作為前置；實際的設施放置、旋轉、供電接線、道路水管、岸邊檢查、供污水與拆除仍由 UI 操作驗證，沒有縮短遊戲時間或跳過供需斷言。

最終驗證：lint、typecheck、production build 通過；908 項完整單元測試通過（單 worker、15 秒上限）。三裝置設施素材／公園／公共服務 9 項及修正前置後的水電 6 項，共 15 項 Playwright 通過；手機直橫式、平板、桌機截圖已檢視。
