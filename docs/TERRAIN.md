# 地形與城市展示（M0-10）

進入應用直接看到 306 棟住宅、商業樓與辦公高樓、道路街廓、斑馬線、路燈、河岸公園、樹木及跨河橋。市中心／河岸／全景按鈕實際操作鏡頭；桌機與觸控手勢沿用 M0-09。這次依使用者要求，將可見城市展示一併加入地形任務，替換早期測試方塊。

## 範圍

城市模型由原創程式幾何與既有 ART 色板生成，沒有外部模型或貼圖。道路、停放車輛和 306 棟建築都是展示物件，沒有居民、交通、財政或存檔狀態；M1 道路／建築任務未標成完成。水面只是平面材質，水深、波紋及動畫留待 M0-11。UI 明示「城市場景預覽」與「建造與經營功能開發中」。

## 地形與資料

- `world/terrain.ts` 不依賴 DOM 或 Three.js：4 octave Simplex Noise 搭配中央平地與山脊遮罩，4.8 km 地圖、301×301 頂點、16 m 間距、0～400 m 高度。
- 固定 seed 的河谷、海灣、山地三個預設由 `data/terrain.ts` 提供，目前 UI 顯示河谷，尚無地圖選單。新增 `simplex-noise@4.0.3` 是 TECH 指定的地形依賴，隨機源由既有 `Rng` 注入。
- MVP 使用種子化導流線，橫向彎曲、河床沿線由海平面下 4 m 降至 8 m，保證連通兩側邊界。這不是自由梯度尋路；GDD §1.2 記錄此階段差異。
- 提供雙線性 `heightAt(x,z)`、中央差分 `slopeAt(x,z)`、多邊形頂點 `flatten(polygon,height)` 與 revision。flatten 目前僅資料 API；尚無編輯工具、資源重算、局部 mesh 更新或 Worker 命令整合。正式模擬不得直接修改主執行緒展示資料。
- 肥沃、森林、礦藏、石油資料為 300×300 的 Uint8Array；用同一 seed 可重建高度與資源。

## 繪製

地形 100 個 chunk（64×64 個 8 m 世界格，邊緣部分不足 64 格）共享材質，Three.js 依包圍球做視錐剔除。自訂片元 Shader 依坡度與高度混合草、乾草、土、岩、沙及兩尺度雜訊；透過 `MeshStandardMaterial.onBeforeCompile` 注入，保留 Three.js 光照、霧與高畫質 CSM，避免另寫一套光照。TECH §6 同步記錄此實作。未擁有地塊保留 40% 飽和度、85% 亮度，邊界用白色虛線。

城市構件按材質與幾何分成五個 InstancedMesh，載入時建立，鏡頭移動不重建幾何。卸載時釋放全部 GPU 資源。Three.js 的 draw call 計數與獨立攔截的四種 WebGL draw API 相符。

## 驗證

- lint、strict typecheck、281 項單元測試、production build 通過。
- 新增地形測試：相同 seed 高度／資源雜湊相同、不同 seed 不同；三預設中央平地比例 ≥70%；河道整條連通且下降；高度／資源範圍；插值、越界與錯誤參數；坡度與多邊形整平。
- 27 項 E2E 通過，另 3 項不適用裝置組合略過。包含三裝置城市按鈕的真實相機距離、44 px 點擊高度、渲染統計、鍵鼠／原生多指、轉向、PWA 離線／更新、WebGL context 恢復。
- 2026-10-06 桌機 Chrome 模擬 iPhone 393×852、DPR 2、中畫質、全圖距離 4000 m：穩定樣本約 60 FPS、54 draw calls、422,842 triangles（包含陰影）。這不是 iOS 實機效能承諾。
- `screenshots/m0-10/`：iPhone 直／橫式、iPad 834×1194、Desktop 1440×900 與市中心近景；三裝置瀏覽器沒有 console error 或 pageerror。
