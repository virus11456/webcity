# 裝置相容性與觸控驗證（M5-05，進行中）

主要玩家使用 iPhone 與 iPad；建造、選單與鏡頭操作以觸控優先。M5-05 尚未完成，以下 Chromium 裝置模擬結果不能當作 iOS Safari 實機驗收。

## 2026-10-13：手機底部工具列修正

使用者回報鎖定／未鎖定工具高度不一致、左右按鈕裁切，觸控操作不容易找到工具。本次處理：

- 手機與平板工具卡統一高度，保留圖示、名稱及解鎖資訊；補齊政策等分類圖示。
- 手機直式每排四個完整按鈕，320px 小螢幕每排三個；保留水平滑動與吸附。
- 新增「全部工具」入口，展開可垂直捲動的分類格；包含建造工具、資訊圖層、財政、城市統計、復原、購地、存檔與暫停選單。點選後收起，鎖定工具不會誤觸執行。
- 手機橫式保留左側工具入口與右側建造面板；展開工具時暫時收起建造面板。
- 建造面板高度配合新入口縮減，保留城市地面可操作範圍；面板內部可捲動。
- 觸控版復原按鈕改為名稱與次數分行，避免動作和退款金額撐寬卡片；完整說明仍可長按查看。

## 2026-10-14：入住前置流程回歸

從空城只鋪道路和住宅，跑到第六天後讀取真實 Worker 鏡像：住宅已完工、容量 17 戶、居民 0、供應旗標 0、逐棟幸福度 0。這符合 GDD §7／§12 的入住條件；空城 HUD 預設幸福度 50 並不代表未接水電的住宅可以入住。

`budget`、`save`、`population` 改為在暫停時透過實際工具建造風力發電、水塔、岸邊排水口、水管及電線，再運行人口模擬。沒有直接修改人口、幸福度或供應旗標。`integration` 保留從主選單新建城市、鋪路、分區的流程，改在住宅完工後接通供應，再等待人口超過 200，並核對實際用水、污水處理與存讀檔一致。

`problems` 沿用水務測試的已入住存檔 fixture，驗證玩家修復供應、拆除電廠後警告、住宅荒廢及人口清除；新居民不會為了測試而被迫入住無供應住宅。新手教學由既有專用案例驗證，建城整合案例明確取消勾選，避免教學面板介入非教學操作。

人口案例不再要求所有住宅同時滿戶：驗證真實入住、就業與各棟容量上限，再核對暫停一致、拆屋搬出、取消商業區後仍保留公共設施工作，以及拆除剩餘設施後失業。近景畫面等待渲染佇列完成，核對渲染建築總數與 Worker 分區建築數一致且有細節模型，允許現行 LOD 依各棟距離選擇細節；不沿用 M1 固定 16 棟的假設。警告操作先切回分區面板，橫式觸控檢查放在警告建築倒塌前。

最終覆蓋三裝置各五組案例，**15 個不重複案例全部通過**：`budget`、`save`、`integration` 的九個案例在三裝置批次通過；`problems` 修正面板步驟後三個通過；`population` 納入公共設施職缺後三個補驗通過。過程中的失敗沒有隱藏，原始 318 案例巡檢數字保留為歷史紀錄；本輪未重跑完整套件，也未解除其他檔案的已知缺口。測試仍是 macOS Chrome 裝置／觸控模擬，未取代 iOS Safari 實機。

人口、警告與整合案例失敗時會附上 `city-state` JSON，保留真實鏡像統計與建築，避免只靠畫面推測。機器可讀摘要見 [2026-10-14.json](compat/2026-10-14.json)。本輪只調整測試與紀錄，未改動產品程式或新增 Vercel 部署。

lint、typecheck 及正式 build 通過，build 保留既有大 chunk 提示。單元驗證保留實際批次結果：預設並行執行為 1,171 通過／14 失敗，失敗均為 5 秒逾時或耗時門檻；改以 `npm test -- --maxWorkers=1` 完整執行為 1,184 通過／1 失敗，唯一失敗是十萬人口每日 P95 31.30 ms 超過既有 10 ms 門檻。隨後單獨執行 `populationScale.test.ts --maxWorkers=1` 通過，未修改測試門檻、逾時設定或模擬程式。此結果覆蓋所有 1,185 項，但不表示本輪完整單元批次零失敗；效能量測的執行環境敏感性仍須在 M5-03／M5-04 處理。

## 2026-10-14：離線音訊與 PWA 回歸（M5-06）

在 `1cc0966` 重現 `buildingGallery` 桌機離線失敗，Playwright trace 的六筆錯誤 URL 均為 `assets/audio/music/*.m4a`。圖鑑使用程序生成建築，施工動畫本身可離線運行；不能把這六筆音樂錯誤當作模型損壞或據此預載全部模型／音樂。

播放器在瀏覽器回報離線時不開始串流、切下一首或重試；連線恢復後由下一次觸控／滑鼠互動繼續，已有網路錯誤的媒體元素重新載入同一首。仍保留音量、隱藏頁面及關閉狀態限制。`navigator.onLine` 是提示而非連線保證；未辨識的網路故障仍以既有每輪最多六首封頂，未加入自動重試計時器或下載整個曲庫。

三裝置回歸另重現音效尚未進入 Service Worker 快取的情形：初次載入可能早於 SW 控制，也可能遇到快取被清除。音效與環境音改在離線時只查 Cache Storage；快取不存在或權限失敗時略過，線上互動再補載缺少的音效，已解碼音效及環境音迴圈不重複建立。

`buildingGallery` 現在刻意清除媒體快取後離線回載，確認施工可操作、沒有音樂請求或音訊錯誤；重連後以手機／平板的實際 `tap()` 恢復一首音樂及十二個音效，再次離線回載確認十二個快取音效仍可解碼。三裝置通過，仍維持六大建築類型、四階段施工、觸控尺寸、iPhone 橫式、GPU 資源及圖鑑篩選檢查。

新增八項單元案例覆蓋離線連續互動、連線中斷後同曲恢復、無法辨識網路故障時的重試上限、靜音／背景／關閉狀態、OGG 缺少時的快取 MP3、Cache Storage 缺少／拒絕，以及重連補載且不重複載入。音效 E2E 原本固定睡眠 160 ms 後讀音量，在桌機與 iPad 曾讀到尚未淡出的訊號；改為一秒內輪詢實際 peak，保留 `<0.0001` 的靜音門檻。

六組 E2E 最終覆蓋 **19 個不重複通過案例、2 個條件跳過**（圖鑑完整枚舉僅桌機執行）。完整批次為 17 通過／2 失敗／2 跳過：iPad 靜音時序與 PWA 30 秒逾時需補驗；修正靜音等待後以單一 worker 重跑三裝置音效與 PWA，六項全部通過，未調高 PWA timeout。原始中間失敗及機器可讀結果見 [2026-10-14-offline.json](compat/2026-10-14-offline.json)。

提交前 `npm test -- --maxWorkers=1` 完整批次 **125 個檔案／1,193 項全部通過**（179.27 秒），包括既有十萬人口效能門檻；未修改門檻或模擬程式。lint、typecheck 及 production build 通過，仍有既有大於 500 kB chunk 提示。

這輪不代表 M5-05／M5-06 全部完成：真機 Safari、Lighthouse、加入主畫面與完整城市離線遊玩仍待驗證，也未重跑 318 案例全量套件。本輪未增加 Vercel 部署。
