# M2-12 交通資訊

Worker 每 2 模擬秒統計各路段目前非行人車輛的平均速度（km/h），除以道路速限並限制在 0–1。交通號誌停等與塞車均計入；行人、建築出入口 segment=0 不計。綠 >70%、黃 40–70%、紅 <40%。空路視為暢通，但道路面板平均速度顯示「目前無車」，不冒充量測值。車數是當下佔用，並非每小時通行量。

`roadTraffic` 事件只傳 id、ratio、count、speedKmh；道路面板重新向 Worker 取得權威值。既有尋路壅塞成本亦使用相同速度比。暫停時維持最後量測；讀檔由已保存車輛、路徑與速度重新計算，不保存衍生統計。

交通圖層共用資訊選單與場景灰階，單一 vertex-color 批次網格沿真實貝茲道路高度繪製，包括高架橋。路網變更才重建幾何，流量更新只改色彩 buffer；離開圖層隱藏、世界卸載時釋放。選擇交通圖層時可直接點道路查看速限、目前車數、平均速度與速度比。
