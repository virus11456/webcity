# M2-18 教育

居民依下一級學歷與年齡申請學位：6–12 歲小學、13–18 歲高中、19–24 歲大學。每一級累積 30 個有效就學日才畢業，沒有學位不會增加學歷。年齡與上班／上學的生活時鐘沿用 M2-07、M2-08；此卡不要求完成可見通勤才計入就學日。

學校必須啟用、未失火且道路可達。招生沿公共服務的道路網路距離，半徑為基礎半徑乘教育預算；同校容量為基礎學位乘預算向下取整。保留仍合格的既有學生，減少容量時優先保留較小居民 ID，其餘按居民 ID 申請最近仍有名額的學校。直線接近但道路不通的住宅不會入學。

小學 300 位／600 m、高中 1,000 位／900 m、大學 4,500 位／1,500 m。停用、拆除、失火、道路中斷或預算減少會重新分配名額；等待期間保留既有就學進度，重新入學後接續累積。超齡者停止入學，不能跳過前置學歷。預算與停用操作即使暫停中也立即反映。

在學者不占用工作職位。畢業後依工作年齡及職缺學歷要求重新媒合；高學歷可填低要求職位，低學歷不能填高要求職位。停用或失火的學校不提供教職職缺。教育服務覆蓋的需求僅計入對應年齡且尚未完成該級的居民，避免已畢業者反覆占用需求。

住宅檢視顯示在學／適齡居民與平均學歷（0–3）；學校顯示在校生／可用學位。個人 `schoolId`、`schoolDays`、`education` 是存檔權威；建築 `education` 是衍生摘要，舊存檔缺少摘要時重建。讀檔不額外計算就學日。

驗證涵蓋容量不足、預算裁減、斷路、停用復學、三級畢業、合格職缺與讀檔。三裝置 E2E 從存檔啟動真實 Worker，停用小學推進一天確認學歷不變，再啟用並完成最後一天；同時確認道路繞行超出招生半徑的住宅沒有畢業。觸控由 Playwright 模擬，另檢查 iPhone 橫式；截圖位於 `screenshots/m2-18/`。
