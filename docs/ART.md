# WebCity 美術規格書（Art Bible）

> 目標：做出接近《Cities: Skylines》的**寫實微縮城市**觀感：明亮自然光、柔和陰影、比例正確、低到中多邊形模型、拉近時有移軸景深。
> ⚠️ 只參考風格，**禁止**使用、描摹或重製 Cities: Skylines 的模型、貼圖、圖示、UI、Logo。所有素材都要原創、程序生成，或使用 CC0 / 可商用授權。

---

## 1. 風格原則

1. **寫實比例、簡化細節**：1 單位 = 1 公尺。建築、車輛、道路尺寸符合真實世界；細節用貼圖與色塊表現，不靠高面數。
2. **從空中看要好看**：玩家 90% 的時間在 100～800 m 高空俯視，所以屋頂要有變化（顏色、斜屋頂、空調箱、水塔），比立面細節更重要。
3. **色彩明亮但自然**：避免純黑純白和螢光色。草地偏黃綠、水偏藍綠、柏油偏暖灰。
4. **分區一眼可辨**：住宅 = 暖色屋頂＋庭院、商業 = 招牌與雨棚、工業 = 灰藍色鐵皮＋煙囪儲槽、辦公 = 玻璃帷幕。
5. **一致性優先**：所有素材共用同一套色板、同一個光照環境，不允許單一模型自帶不同風格的光影或描邊。

## 4. 光照與後製（Three.js 參數）

| 項目 | 設定 |
|---|---|
| Renderer | `WebGLRenderer({ antialias: false, powerPreference: 'high-performance' })`，`outputColorSpace = SRGBColorSpace` |
| Tone mapping | `ACESFilmicToneMapping`，`toneMappingExposure = 1.0` |
| 太陽 | `DirectionalLight` 色 `#FFF1DC`、強度 3.0，白天仰角 35°～60° |
| 環境光 | `HemisphereLight` 天空 `#BBD7F0`、地面 `#6B7A4F`、強度 1.2 |
| 陰影 | 高：CSM 3 段、2048；中：單張 1024，跟隨鏡頭焦點 600 m 範圍；低：關閉。`shadow.bias = -0.0005`，`normalBias = 0.02` |
| 霧 | `FogExp2`，色 = `sky_horizon`，密度 0.00012（鏡頭越高密度越低，避免遠景全白） |
| 天空 | 自訂天空球 Shader：天頂→地平線漸層 + 太陽光暈；日夜時插值 |
| 移軸景深 | 自訂 Pass：以畫面中心偏下為焦點，上下 30% 區域漸進模糊；強度依鏡頭高度：< 60 m 為 0、150～600 m 最強、> 1200 m 為 0 |
| SSAO | 僅高畫質，半徑 4 m、強度 0.6 |
| Bloom | 僅中、高畫質且夜晚啟用，閾值 0.9、強度 0.6 |
| 抗鋸齒 | FXAA（中、高），或 DPR ≥ 2 時關閉 |

## 5. 地形與水

### 5.1 地形 Shader
- 依**坡度**與**高度**自動混合：草地（坡度 < 20%）、泥土（20～35%）、岩石（> 35%）、沙灘（水岸 ±3 m）、乾草（高度 > 200 m）。
- 每種材質用 512×512 可平鋪貼圖（三平面投影避免陡坡拉伸），加上 2 層不同尺度的雜訊（32 m、256 m）打破重複感。
- 建築與道路下方地面自動壓平並改成泥土 / 草地（施工中顯示泥土）。
- 未擁有的地塊：飽和度 −60%、亮度 −15%，地塊邊界畫白色虛線。

### 5.2 水 Shader
- 兩層滾動法線貼圖（不同方向、尺度 8 m 與 40 m）。
- 顏色：依水深（地形高度與水面差）在 `water_shallow` → `water_deep` 插值。
- 菲涅耳：俯視時透明度高看得到河床，斜看時反射天空色。
- 岸邊泡沫：水深 < 0.8 m 處疊加雜訊白邊並隨時間流動。
- 河流有流向：法線貼圖沿流向移動。
- 污染：水污染值越高顏色越偏 `#6B5A3A`（褐色）。

## 6. 道路視覺

- 道路 Mesh 依路段曲線動態產生，橫斷面（由外到內）：路緣 → 人行道（`sidewalk`）→ 路緣石 → 車道（`asphalt`）→ 分隔線。
- 標線：雙向道中央黃色雙線（四線道以上）或白色虛線（小路）；同向車道間白色虛線（3 m 實 / 6 m 空）；路口前停止線。
- 路口：圓角轉彎（半徑依道路寬度 6～12 m）、斑馬線（紅綠燈路口）。
- 林蔭小路 / 大道：分隔島或人行道上種樹（Instancing）。
- 高架 / 橋：路面下方有橫樑與橋墩（混凝土 `#B5B2AA`）。
- 路燈與交通號誌為獨立 Instanced 物件。
- 施工預覽：半透明藍色（可建）/ 紅色（不可建）的道路 Mesh。

## 7. 建築

### 7.1 程序生成建築（MVP 到 Alpha）
所有建築先用程式產生，目標是「從空中看起來像 CS 的城市」。生成器輸入：`zone, level, lotWidth, lotDepth, seed`。

**體量（Massing）**
| 分區 | 規則 |
|---|---|
| RL | 主體為長方體或 L 形，**斜屋頂**（雙斜 / 四坡，屋頂出簷 0.4 m），1～2 個小附屬（車庫、門廊）；前院草地＋步道、後院草地＋1～2 棵樹；可選矮籬笆 |
| RH | 基座（1～2 層，略寬）+ 塔身（矩形或 L 形），平屋頂 + 女兒牆 + 屋頂設備箱 / 水塔；陽台以水平帶狀表示 |
| CL | 1～3 層長方體，一樓店面玻璃 + **彩色雨棚** + 招牌板；平屋頂 + 空調箱 |
| CH | 基座商場 + 1～2 個退縮塔身，屋頂設備；大型招牌 |
| I | 大型低矮廠房、**鋸齒屋頂**或弧形屋頂；附加物隨機：煙囪（20～40 m，紅白條紋）、圓柱儲槽、貨櫃、卸貨平台、圍牆；地面為水泥 `#A9A59C` |
| O | 玻璃帷幕塔，2～3 段退縮，頂部收細或斜切；屋頂停機坪 / 天線 |

**窗戶貼圖**：用 Canvas 產生一張 1024×1024 貼圖集（Atlas），包含每種分區 4～6 種窗型（單窗、帶狀窗、玻璃帷幕、店面），以**每層一列**的 UV 對應到牆面；另一張同 UV 的自發光遮罩貼圖用於夜晚亮燈。

**隨機規則**：同一個 seed 必定產生相同建築；同一條街上相鄰建築避免同色（換色板索引）。

**面數預算**：程序建築每棟 ≤ 600 三角形（RL）/ ≤ 1,500（RH、CH、O）。

### 7.2 正式模型（Beta，Blender 製作）
- 格式：glTF 2.0（`.glb`），Meshopt 壓縮，貼圖 KTX2（Basis UASTC/ETC1S）。
- 原點：地塊正面中央、地面高度；+Z 朝向道路。
- 每個模型提供 LOD0 / LOD1 / LOD2：
  | | LOD0 | LOD1 | LOD2 |
  |---|---|---|---|
  | 低密度建築 | ≤ 1,500 tris | ≤ 300 | 盒子 12 tris |
  | 高密度建築 | ≤ 4,000 | ≤ 600 | ≤ 24 |
  | 車輛 | ≤ 600 | ≤ 100 | 不渲染 |
  | 樹 | ≤ 400 | ≤ 60 | Billboard |
- 切換距離：LOD0 < 250 m、LOD1 < 900 m、LOD2 之外。
- 貼圖：共用 Atlas（每個分區一張 1024×1024 顏色 + 一張自發光），不使用個別貼圖。
- 材質只允許：`MeshStandardMaterial`，roughness 0.7～0.95，metalness 0（玻璃 0.3、金屬屋頂 0.4）。
- 命名規則：`bld_{zone}_{level}_{w}x{d}_{variant}.glb`，例：`bld_rl_l2_2x2_03.glb`；服務建築 `svc_{id}.glb`；車輛 `veh_{type}_{variant}.glb`；道具 `prop_{name}.glb`。

## 8. 車輛與行人
- 車輛色（隨機加權）：白 25%、黑 15%、銀灰 20%、深藍 10%、紅 10%、其他（綠、黃、咖啡、淺藍）20%。

## 11. 音效與音樂方向
- 音樂：輕快、樂觀的器樂（鋼琴、吉他、弦樂、輕電子），每首 3～4 分鐘，至少 6 首隨機輪播；授權需允許商用（自製、委託或 CC-BY 標註來源）。
- 環境音：依鏡頭高度與畫面內容混音 —— 近地面：車流、鳥叫、人聲；高空：風聲；靠近工業區：機械聲；靠近水邊：水聲。
- UI 音：點擊（短、柔）、放置建築（「咚」＋塵土）、拆除（碎裂）、鋪路（連續滑動音）、里程碑（短號角）、錯誤（低音嗶）。
- 格式：音樂 AAC/MP3 128 kbps 串流；音效 OGG + MP3（Safari 備援），單檔 < 50 KB。
