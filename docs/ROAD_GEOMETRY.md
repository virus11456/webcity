# M1-04：地面道路吸附與建造檢查

此卡提供純函式供主執行緒預覽與 Worker 建造驗證共用。M1-05 已接入鋪路工具與扣款，詳見 `docs/ROAD_TOOL.md`；橋梁、高架與曲線仍屬後續任務。

## 共用 API

- `previewStraightRoad(request, world)`：回傳 `canBuild`、`reason` 和 `preview`。preview 包含 RoadDraft、兩端吸附目標／高度、平面長度、整數費用、最大縱坡與全寬占地。非法座標或高度圖沒有可用預覽時回傳 null。
- `snapRoadPoint(point, world, enabled)`：距離嚴格小於 8 m，先節點再路段；每類取最近者，同距離依 ID 排序。回傳複製的座標，路段中間的高度線性內插。此版本不吸附高架道路與離地節點。
- `snapRoadVector(start, end, referenceAngle, options)`：15° 角度與 8 m 長度吸附可獨立關閉，referenceAngle 使用弧度。
- `roadConstructionCost(type, length)`：平面長度按每 8 m 單價比例計算，最後才向上取整至整數遊戲幣。吸附到接點後的非 8 m 長度不多收整個 8 m 單位。
- `RoadGraph.previewRoad(snapshot, road)`：複製可信任的世界道路資料，再走與真實建造相同的圖驗證；不改變原圖，也不消耗全域 ID。供 preview 使用，不是存檔反序列化或不可信資料的入口。

世界輸入含高度圖、已購地塊、建築占地及 nodes / segments / nextId，對應既有 WorldSnapshot；以 terrain.heights 傳入 heights 即可。這是可信任城市資料，須維持 ID、鄰接及型別不變量，不接受任意外部 JSON。公開預覽 request 會檢查座標、道路種類與地圖邊界；未處理預算、解鎖或不可信 Worker 命令解碼，這些由 M1-05 的指令層負責。

## 吸附順序

1. 起點先找節點／路段，終點先嘗試直接接點。
2. 沒有直接接點時，終點依起點相連道路方向吸附角度與長度；多分支選與游標偏差最小的方向，ID 決定相同偏差的先後。沒有參考道路時用世界 X 軸。
3. 取整後再檢查一次接點，避免取整造成小縫隙。精確接點優先於角度／長度，所以 T 字接入可以保留 73 m 等非整格長度。
4. `snap.angle`、`snap.length`、`snap.connections` 各自控制開關。此卡提供計算選項，沒有實作 Shift 或工具列。

## 占地、地形與錯誤

道路占地為端點間的全寬矩形，端部不額外延伸。使用凸多邊形裁切判斷地塊與建築面積重疊，只有接觸邊界時允許。建築以 TECH 的正面中心為原點，rotation=0 時寬沿 X、深沿 +Z，旋轉採 Three.js 的正 Y 旋轉方向；所有建築狀態均占用地塊。

地形沿用渲染及 picking 的三角形對角線，將道路占地裁切到每個相交三角形。平面函式的最低高度在交集頂點取得，縱坡取梯度沿道路方向的投影絕對值；再包含兩端連接高度的縱坡。這能發現窄小水域及端點等高的中途山坡，並非固定間距點取樣。橫坡目前交由後續道路下方地形平整處理；此卡不改變地形。掃描先按地形列裁切道路範圍，避免長斜線掃描整個包圍方框。

最大一般道路縱坡 12%，高速與匝道 6%。海平面恰好 40 m 可建，低於海平面拒絕。`data/roadGeometry.ts` 的 1e-5 坡度容差處理 Float32 高度差捨入，1e-6 金額容差處理浮點運算；它們不是遊戲平衡值。

驗證依序回傳第一個原因：非法輸入 → 原始地圖邊界 → 最短路段 → 吸附後完整占地邊界 → 已購土地 → 地形有效／水域 → 縱坡 → 建築 → 道路圖重疊、切割後短段或小夾角。原因均有 `zh-TW` 對應文字。若提早失敗，preview.slope 可能只包含端點縱坡，工具應以原因為主要提示。

## 整合與測試

API 沒有 DOM、Three.js 或模擬層相依，也不修改高度圖、建築、金錢或圖。道路圖試算會複製資料；後續工具應只在輸入／世界版本改變時重新計算，不放在無變化的渲染迴圈。大量道路與建築的空間索引仍待整合時量測，不宣稱滿足大型城市每幀預算。

測試涵蓋每種吸附、所有錯誤 key、八種路型造價、接點優先順序、原圖不變、三張生成地圖、跨地塊長道路、長斜線、小面積水域、山坡與旋轉建築。

## 已記錄的後續居民需求

GDD §7.2 與 M2-07～M2-11 已補上每人自己的住家、工作／職務／班表、不同目的地的通勤路線、下班回原住家及睡眠。這是需求紀錄，尚未實作居民、行人或車流；M2 行程任務須先解決財政日與可視通勤的時間尺度。

M1-05 整合補充：connections 支援 exact 模式供 Worker 重驗已定位草稿，僅重用同點接點；地面預覽採實際地表作為路口及路段內部接點高度，避免地形起伏造成假立交。其餘 M1-04 吸附與驗證規則不變。
