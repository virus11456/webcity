# M3-15 城市特效

ART §9 特效已接到實際城市的唯讀事件與建築狀態：

| 效果                       | 行為                                                                                                                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 工業／燃料電廠／焚化爐煙霧 | 灰白 GPU instanced billboard；高畫質每座 40 顆、中畫質 16 顆，最多 64 座、1,200 m 內顯示。位置跟隨工業煙囪與電廠煙囪，GPU 依時間計算上升與飄移。停用、施工、燃燒、拆除的來源停止冒一般煙。 |
| 火災                       | 保留橘紅火焰與黑煙批次，分區建築依屋頂高度放置，避免被高樓遮住；分區建築染黑。電力與水務設施也會在收到火災／燒毀更新時即時更新材質，單純傷害數字變化不重建。                               |
| 施工                       | 保留地基泥土、逐步結構與立面、鷹架及大型建築起重機。                                                                                                                                       |
| 升級                       | Worker 確認高等級建築完工／等級提升後，底部淺藍光環向上擴散 0.8 秒；重複狀態不重播。                                                                                                       |
| 放置                       | 保留 0.25 秒縮放彈跳與塵土。                                                                                                                                                               |
| 拆除                       | 保留 0.4 秒下沉與塵土；渲染結束不改寫 Worker。                                                                                                                                             |
| 問題                       | 保留屋頂 billboard，輕微浮動。                                                                                                                                                             |

低畫質停止煙霧、火焰、升級光環、塵土、放置彈跳、下沉、起重機與裝飾鷹架，以及問題圖示的浮動。必要的靜態資訊（未完工結構、地基、火災染黑與問題圖示）仍然保留。畫質可在暫停選單即時切換；自動畫質降級也會套用。沒有主執行緒模擬寫入。

CityEffects 只有兩個預配 GPU 批次，無逐幀新幾何或每粒子新物件。原創程序效果無外部貼圖或版權素材。`?debug=1` 的 `__webcityEffects()` 提供煙霧粒子、火災、光環與畫質計數。

測試涵蓋每座粒子上限與總預算、距離剔除、來源狀態、重複升級事件、0.8 秒到期、低畫質關閉／恢復，以及設施染黑。瀏覽器使用有效城市存檔，讓 Worker 真正完成建築，再捕捉升級光環並切換高／低／中畫質；截圖在 `screenshots/m3-15/`。

驗證：lint、typecheck、build 通過；完整單元測試 920 項通過。特效、施工、火災、電力與供水跨裝置回歸 16 項通過，兩項既有 5,000 棟壓力測試僅在桌機執行；屋頂火焰修正後，特效及救援 6 項跨裝置重驗通過。截圖採 Chrome 裝置模擬，未宣稱 iOS 實機測試。
