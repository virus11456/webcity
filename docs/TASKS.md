# WebCity 任務卡（給 AI 執行）

> 每張任務卡都是一個獨立的工作單位，對應一個功能分支和一個 PR。
> 執行順序：依「相依」欄位，同一階段內沒有相依關係的任務可以平行進行。
> 估時以單人工作天計，僅供排程參考。

---

## 使用者確認的遊戲範圍（2026-10-06）

- 保持手機操作流暢；展示城市需逐步接上真正的鋪路、住宅／商業／工業分區及建築成長（M1-05～M1-12）。辦公另依 O 分區處理。
- 人口需有搬入、搬出與就業，不是固定展示數字（M1-13、M1-14）。
- 電力、供水、污水及垃圾必須影響城市運作（M1-15、M1-16、M4-07；GDD §9.3 的 M1 簡化垃圾覆蓋仍需安排具體任務）。
- 公共服務包括警察、消防、醫院（M2-15～M2-17），以及殯葬服務、墓園、靈車與火化（M4-08）。
- 上述是後續實作要求，尚未因展示模型或這份紀錄而視為完成。

## 如何把任務交給 AI

把下面這段**任務提示詞範本**貼給 AI，替換 `{任務ID}` 即可：

```
你是 WebCity 專案的開發者。這是一款以 TypeScript + Three.js 開發、
玩法與美術風格參考 Cities: Skylines 的網頁城市模擬遊戲（PWA，支援 iPhone / iPad / PC）。

請依序閱讀：
1. AGENTS.md（開發規則，必須遵守）
2. docs/TASKS.md 中「{任務ID}」這張任務卡
3. 任務卡「參考」欄列出的 docs/GDD.md、docs/ART.md、docs/TECH.md 章節

然後：
- 從最新的 main 建立任務卡指定的分支
- 完成任務卡「內容」的所有項目
- 確認「驗收標準」每一項都通過（lint、typecheck、test、build 必須全綠）
- 依 AGENTS.md 的格式 commit、push，並開 PR 到 main
- PR 說明列出驗收標準逐項勾選結果，UI / 視覺相關任務附上 iPhone、iPad、桌機三種尺寸截圖

如果文件有矛盾或不清楚的地方，選最符合 GDD / ART 精神的做法，並在 PR 說明「待確認事項」中列出。
不要做任務卡範圍以外的功能。
```
