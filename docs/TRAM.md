# M4-03 道路電車

先建公車總站，再選「電車」並沿道路設站。「計算鋪軌費用」只向 Worker 報價，顯示總價後按「沿路鋪軌並開通」才建立路線與扣款。每條使用道路 $30／8 m，按線分別計費；總站和公車共用 20 個車位，電車每車 90 席、$60／週、單次上車 $3。減車、刪線及個別乘客的步行／搭乘／存檔沿用公車流程。

電車使用與汽車相同的車道、跟車間距、號誌及路口保留。它不沿道路中心任意穿越其他車輛；每輛 18 m，使用 M3 原創軌道車體。車輛由總站配置到起站發車，沒有在無軌道路上模擬出庫。路線上限 6,400 m，拒絕要求變換車道的路徑；未提供架空電纜、轉乘及專用路權。軌道會顯示實際車道和路口曲線，停用總站仍保留軌道；拆路移除該段軌道，刪線移除其軌道且不退費。道路切割／拆除造成替代路線超出既有軌道時必須重建路線。
