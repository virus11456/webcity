# M1-09 拆除工具

## 操作與退款

先「開始鋪路」建立道路，再切換「拆除」。點選單一路段；點在三岔以上路口中心 6 m 內會選取全部相連路段。拖曳會沿掃掠路徑累積物件，放開才整批拆除。紅色預覽及面板顯示物件數、退款與清理費。Escape、右鍵、雙指或切換工具取消尚未提交的選取；雙指仍操作鏡頭。每筆上限 256 個目標。

- 建成未滿七個完整遊戲日（`0 <= day - builtDay < 7`），退還記錄的實付建造費 `paidCost`；第七日開始不退款。
- 道路切段依長度用累計整數分配原實付費，最後一段承接餘額；保留原建造日，避免切段後重複退款或重設期限。
- 沒有付款記錄的舊資產不推算退款；sandbox 不產生退款。分區自行生長的建築不退款。
- 廢棄／燒毀建築收取 `$100 × 占地格數` 清理費，允許負資金；暫停時仍能拆除。
- 建築及管線的選取／交易介面已實作並以資料測試驗證；目前尚未開放建築生長、服務建築或管線放置，選單有提示。

## 權威資料與同步

`world/bulldoze.ts` 純函式規劃整筆交易。Worker 在放開指標後重新驗證所有 ID 與費用，任一目標失效即整批拒絕；重複 ID 只計算一次。成功才更新道路圖、分區、建築與管線，並發送對應變更事件與實際退款。待回覆期間鎖定工具切換，逾時不自動重送。

刪路會清除其分區格、更新剩餘區塊與建築占用索引，移除孤立節點、修正鄰接與路口號誌。刪除 T 字一臂後保留兩條既有路段及中間節點，維持各自 ID、建造日、實付費與格線相位，不強制合併。道路及分區渲染器依 Worker 事件更新。

原本臨路的建築失去地面道路時，立即記錄 `roadDisconnectedDay`，每天累計 `problemTimers.noRoad`。連續三十個完整遊戲日無道路則廢棄、清除入住／工作容量並減少人口。重新接路清除失聯時間，但不自動復活已廢棄建築。拆除建築會釋放占用格、扣除原居民數並同步人口統計、保留仍存在的分區。

前端使用唯讀鏡像與快取選取形狀，不逐幀複製世界；預覽幾何只在選取或地形變更時重建。道路床已整平的地形不還原，因目前沒有原始地形修改歷史。展示街區仍是裝飾模型，無法以此工具拆除；道路／分區尚無存檔，重新整理會重建空白遊戲世界。

## 驗證

提交驗證：lint、typecheck、502 項單元測試、build；完整三裝置 E2E 56 項通過，7 項裝置不適用跳過。最後人口同步修正另重跑三裝置拆除流程。截圖見 `docs/screenshots/m1-09/`。

新增 36 項單元測試，涵蓋退款邊界、切段費用守恆、陳舊目標整批失敗、路口／孤點清理、分區與建築索引、斷路三十日及復路、建築／管線拆除、負資金與 Worker 鏡像、工具取消及非同步回覆。

Playwright 使用原生滑鼠與 Chromium CDP 觸控模擬，於 iPhone 15、iPad Pro 11、Desktop 驗證鋪交叉路→塗分區→預覽→取消→拆單臂→拆路口、快速拖曳兩路、七日後零退款，以及 44px 控件、手機橫式與無頁面捲動。這是桌機 Chromium 裝置模擬，未宣稱實機或 Safari 驗證。

M1-17 起，道路失聯仍由本模組立即標記，統一問題系統接手完工建築的連續 30 天計時、廢棄與 60 天倒塌。修復時清除道路問題；施工階段不累積廢棄時間。詳見 `BUILDING_PROBLEMS.md`。
