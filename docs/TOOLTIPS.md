# M5-02 提示系統

主工具列、道路／分區／服務設施等建造卡片、需求條及常用的時間、財政、存讀檔控制提供操作說明。卡片讀取既有資料表顯示造價、維護費及目前解鎖／前置條件；不增加模擬或存檔欄位。

- 桌機滑鼠停留 350ms 顯示提示；可把游標移入提示閱讀，離開後 150ms 收起。
- 觸控長按 550ms 顯示，放手仍保留；這次放手產生的 click 不會選取物件或執行儲存。下一次正常點擊照常操作。
- 按住期間移動超過 8 CSS px、開始雙指、取消觸控、捲動外部容器、失焦或改變視窗大小，都取消提示。沒有接管畫布事件或 pointer capture。
- 鍵盤焦點立即顯示，Esc 關閉並保留原焦點；焦點移動造成的捲動會重新定位提示。提示使用 `role=tooltip`，暫時加入自己的 `aria-describedby`，不刪除原有說明 ID。
- 提示跟隨目標位置，受可見視窗與安全區限制；存檔等原生對話框中的提示掛在該對話框內，避免被 modal 層遮擋。提示內沒有操作按鈕。

文字集中 `t()` 字典、數值集中 `data/tooltips.ts`、色彩沿用 UI tokens。`main` 註冊單一委派控制器，支援後續新增／移除的控制元件；只有提示顯示期間觀察目標所在 UI 的變化，關閉時解除觀察。pagehide 清理全部事件、計時器與 DOM，沒有每幀掃描。

自訂說明使用 `data-tooltip`；既有控制鈕依明確的在地化標籤取得用途說明，native title 作備援。只重複按鈕名稱的 title 不再產生額外提示，避免影響關閉面板等控制的 Esc 操作。原本 UI kit 的獨立說明按鈕保留原有點擊行為。

驗證包含真實 hover、Chromium CDP 長按與多指事件、拖動取消、放手不選取／不儲存、正常點擊、鎖定卡片、鍵盤與既有 ARIA 說明保留、目標移除、對話框與手機橫式。觸控為瀏覽器模擬，沒有宣稱實機 Safari 測試。
