# M4-11 獨特建築與地標

工具列「獨特建築」提供 M3-12 的十二款原創模型。第一批六棟在 MS8 解鎖，第二批六棟在 MS10；每棟另需一項已啟用的公共設施，完整價格、維護、條件與效果見 GDD 的 M4-11 表。卡片直接顯示條件與效果。

每種全城一棟，停用與燒毀仍占名額；拆除後才可重建。沙盒免解鎖與費用，但仍限制唯一性。條件在建造時檢查，前置設施後來停用不會抹掉地標。Worker 與預覽共用 uniqueReason，資金不足、重複建造或條件不足都不扣款。一般模式仍需要合法地形、持有土地與臨路位置。

地標的實際效果採公園系統：提供表列半徑內線性衰減的地價加成，間接改善幸福度與區域升級；預算控制半徑、強度及維護費，停用、著火、燒毀沒有加成。不新增未定義的觀光收入或虛構人口，市民也可將地標作為休閒目的地。地標使用 unique 建築類型，不產生虛構服務職缺。

存檔保留建築、已付費用與開關；讀檔拒絕重複的地標記錄。既有存檔沒有地標時無須遷移。美術模型 ID 與原有 42 個設施資產不變，目錄不再重複添加純美術地標。

驗證：十二棟逐一檢查里程碑／前置設施、扣款、地價效果、停用、重建、存讀檔；另檢查沙盒限制、資金不足、預算與燒毀效果、畸形存檔。E2E 使用 Chromium 的三種裝置設定與手機橫式，實際建造、檢查唯一性與存讀檔；不是 Safari 真機結果。
