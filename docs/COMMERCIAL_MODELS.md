# 商業、工業與辦公模型（M3-11）

新增 CL 36（3 級 × 1×1／1×2／2×2／2×3 × 3）、CH 18、I 27、O 18（後三種地塊為 2×2／3×3／4×4），共 99 個原創 GLB，合計 2,400,692 bytes。連同住宅共有 189 個正式模型。未列入的地塊組合仍保留程序建築，舊存檔不用遷移。

每個模型含三段 LOD、Meshopt 幾何、分區共用的 1024×1024 KTX2 顏色與夜窗 atlas；roughness 0.85、metalness 0、頂點色使用 ART 色板。正面中央原點、+Z 朝道路。建築已有的施工／狀態／資訊圖層流程不變，載入器按分區共用 GPU 材質。

商業保留店面、彩色雨棚和招牌，新增立式店招、支柱與屋頂通風設備；工業保留鋸齒屋頂、條紋煙囪和儲槽，新增裝卸防撞柱與肋條貨櫃；辦公塔保留玻璃帷幕、退縮塔身、停機坪與天線，入口增加玻璃門廳和白框。工業中景保留煙囪，高樓遠景合併上部體量，避免只取前兩段造成少掉頂部。

使用 `npm run assets:models -- cio` 重建；原始 atlas、參數、三段面數、bytes 與輸出 URL 保存於 `assets-source/catalog/`。沿用 M3-10 原創離線參數化製作的決定，非 Blender 手工模型或外部商業遊戲素材。沒有新增依賴或改變模擬容量。全城切換策略接續 M3-14。

單元檢查涵蓋 189 個模型的命名、hash、Meshopt/KTX2、LOD 面數與原點、確定性 mapping，以及高樓遠景高度。瀏覽器使用明確的 99 棟展示存檔，驗證下載失敗仍有建築、恢復後載入正式素材；三種尺寸檢視四種分區與手機橫式。這是本機 Chrome viewport 模擬，不代表 iOS 實機驗收。

驗證結果：lint、typecheck、production build 通過；完整單元測試 904 項通過（單 worker、15 秒上限）；6 項 Playwright 住宅與商業工業辦公回歸全部通過。已實際檢視三尺寸與手機橫式截圖。
