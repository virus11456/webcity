# M3-04 天空與光照

白天沿用 ART §4：SRGB 輸出、ACES Filmic、曝光 1；太陽暖白 #FFF1DC、強度 3，方向 [-1, 1.5, 1]（仰角約 47°）；天空／地面半球光強度 1.2。漸層天空球跟隨鏡頭，只顯示天頂、地平線與太陽光暈，不寫深度、不受場景霧影響。

霧色與天空地平線一致。FogExp2 在海平面以上 80 m 內保留密度 0.00012，80–2000 m 以 smoothstep 平滑遞減至 30%，更高處保持該下限。使用海拔基準避免跨山頭時突然改變密度；此範圍是 ART 未明訂的視覺參數，集中在 data/rendering.ts。每幀只修改既有霧密度，不建立物件。

測試涵蓋密度邊界、連續性、有限輸入、單調下降與既有光源資源生命週期。瀏覽器實際移動鏡頭並讀取 renderer 傳出的密度，檢查 iPhone、iPad、桌面街景／全景及手機橫式截圖；這是 Chrome viewport 模擬。
