# M4-07 完整垃圾收運

住宅按入住戶每日 1 單位、工作場所按職位每日 0.8 單位產生垃圾，保留 M4-05 回收政策的 0.8 倍。Building.garbage 為持久庫存，超過 200 顯示垃圾圖示及通知、降低幸福度；持續 40 天依既有問題規則廢棄。不存在覆蓋半徑內自動刪除垃圾。

公共服務選單開放掩埋場（MS1，$6,000／$240 週）、焚化廠（MS4，$32,000／$960）、回收中心（MS6，$18,000／$640）。都必須臨道路，沿用 M3 原創 4×4 格設施模型與服務坡度規則，可暫停／啟用。垃圾預算影響可派車數（6／10／8 乘預算後向下取整）及每日處理量；已出勤车辆會完成往返。

每輛垃圾車載重 100 單位，至少 1 單位才派車。沿真實有向車道路徑前往一棟建築收集，再駛回所屬設施卸載；沿用交通壅塞與斷路停留／重試，每 tick 最多 4 次路徑請求、全市 300 個任務，失敗 20 ticks 後重試。每次只服務一棟，下一趟重新選擇，並用輪替目標避免固定建築壟斷。車上垃圾只在抵達設施後入庫。垃圾車為公共服務車，重型貨運禁令不限制垃圾車。

派車前預留設施剩餘容量，避免多車同時返回超量。掩埋場容量 80,000，不自行減少；滿了在建築檢視、問題圖示與城市通知警告，可另建處理設施。本卡未加入掩埋場清空／轉運指令。焚化與回收設施的暫存容量為各自兩日基準處理量（4,000／2,000），每日最多處理 2,000／1,000 乘垃圾預算，無垃圾或停用／火災不處理。焚化發電依當日實際處理量／2,000 比例，最高 8 MW，再套用電力預算；不會空燒產生電力。

拆除或燒毀出勤車所屬設施時，撤銷任務並把車上垃圾退回原建築；原建築也已拆除則記入 garbage.lost。這是取消交易的保存規則，不是成功收運；一般停用不撤銷已出勤車。返回途中原建築拆除仍可用已保存的取貨位置完成回程。未派車、斷路或設施滿載時，垃圾保留在原處／車上。

WorldSnapshot.garbage 保存任務及累積已收集、已處理、遺失量；Building.wasteFacility 保存库存、當日處理、日戳、滿載與出勤車數。TrafficKind.garbage=6，任務 purpose=9 使用共用負 citizenId 與 mission id 分配。舊存檔新增空狀態，存檔驗證跨系統 id、往返方向、載重、庫存預留容量及車種。檢視垃圾車顯示任務階段、所屬設施與車上實際載重。

驗證包括抵達前不收集、回程前不入庫、同時派車不超量、滿載警告、預算車隊、停用與斷路、修路後恢復、處理日戳與發電、行進中存讀檔、拆除退回及正常工具解鎖。三裝置 E2E 透過正常速度按鈕驗證車輛位置變動、垃圾減量、滿載檢視、手機橫式停用／啟用及存讀檔。
