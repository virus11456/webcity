# 地圖選擇（M4-17）

新遊戲保留河谷平原、海灣、群山之間，新增隨機地圖；每種選項皆有以實際高度圖產生的全境縮圖。中央白框標示初始地塊，縮圖不含道路與建築。預設選項會回填原先固定種子；玩家仍可自行修改。

隨機地圖由種子決定 0.7–1.5 的山勢幅度與 35% 海岸機率，保留既有中央宜居平地、連通河道及資源場。換圖按鈕使用瀏覽器 crypto 產生新種子，Worker 不使用非確定隨機。種子以既有 unsigned 32-bit RNG 語意解讀；相差 2^32 的碼可能相同。

預覽與 Worker 共用 resolveMap 與 Terrain，生成時間由輸入停止後 120 ms 排程，取消舊排程；離開選單即清理。沒有額外 WebGL canvas 或 runtime 套件。存檔記錄 random 身分、種子、實際高度與資源；已存地形不會於載入時重新洗牌。

保留 M0 的種子化河道，不在本卡替換全域水文演算法。既有三張固定地圖的高度不變。
