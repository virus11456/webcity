# 道路升級（M2-03）

在道路工具選擇「升級／反向」，再選目標道路種類。桌機點一下既有路段即升級，按住拖曳可選取多段；觸控選取後按確認。工具顯示累計差價與受影響建築數。同一筆拖曳每個路段只處理一次。選擇與既有道路相同的單行道種類會反向。

Worker 每段重新驗證解鎖、資金與幾何，費用為 `max(0, 新道路建造費 − 舊道路建造費)`；降級不退款，沙盒不收費。多段依序處理，若期間世界改變導致某段失敗就停止，已成功的路段保留。取消未送出的選取不扣款。

拓寬只移除與新路面實際重疊的建築，其餘保留 ID 與人口資料。縮窄後原建築留下通往道路的退縮距離，後續連接檢查與存檔保留此距離。分區依新寬度重建，重疊且方向相符的格子保留。單純反向保留所有實體分區；`zoningReversed` 使後續重建和切割仍使用原分區方向。

退款不因免費反向或降級而重設道路年齡。七日內升級的差價併入原道路付款，沿用原到期日；原道路退款已到期時，只有這次付出的升級差價開始新的七日退款期。
