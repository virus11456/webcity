# 天氣（M4-13）

城市種子與模擬 ticks 決定天氣，每 300 ticks（正常速度 72 秒）換一段。晴天 40%、雨 25%、霧 15%、雲影 20%，段落首尾各 15% 平滑淡入淡出；讀檔可還原相同時刻，不消耗模擬亂數。暫停會停止雨與雲影，快轉沿模擬時間前進。

設定中的「天氣（雨、霧與雲影）」預設開啟，可立即關閉，選擇保存在此裝置；舊設定自動補為開啟。它只影響畫面，不改變人口、交通、災害機率或水流。

雨使用單一 LineSegments 批次與頂點 shader，低／中／高畫質為 200／500／1,000 條；霧增加 FogExp2 密度，上限 0.0015；雲影在地形材質以共用時間 uniform 移動，並降低日夜系統的日光／環境光。停用立即歸零，畫質切換會重新安裝地形 shader。

驗證：4 項天氣單元測試涵蓋可重現分布、邊界、暫停、開關、畫質、資源釋放與舊設定。Playwright 覆蓋三種裝置、手機橫式、雨的時間推進、設定保存、畫質切換、霧與雲影，並檢查瀏覽器錯誤。不宣稱真機 Safari 或大型城市效能已驗證。
