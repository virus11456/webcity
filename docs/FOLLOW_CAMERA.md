# M2-24 跟隨鏡頭

點選車輛／行人，在資訊面板選「跟隨」。面板收起，鏡頭保持原方位與傾角，以 100 m 距離平滑追蹤選定實體 id 的插值位置；道路高架高度也納入焦點。畫面顯示跟隨 id 與取消提示。

任何 pointerdown（包含 UI 與觸控）、滾輪、按鍵（含 Esc）、視窗失焦或尺寸改變都取消。手動鏡頭平移／旋轉／俯仰／縮放也取消。停止時保留目前地點，不返回舊位置。跟隨期间停用邊緣捲動，取消後恢復玩家設定。

跟隨對象抵達並從車輛事件移除時立即取消，不跳到另一位居民。暫停模擬使對象停住，鏡頭可完成平滑靠近後靜止。存檔只保存模擬，不保存臨時跟隨 id；切換城市清理狀態與監聽器。

`VehicleRenderer.copyPosition` 寫入重用座標物件，`FollowCamera` 在鏡頭更新前取得畫面插值位置，沿用與 FPS 無關的阻尼。每幀無新增追蹤物件或 Worker 請求，不改變個人路徑或交通模擬。
