# 地形拾取與格子（M0-12）

為鋪路、分區與建築放置提供地形選取基礎。一般頁面仍維持城市展示，沒有建造功能；加上 `?debug=1` 可用滑鼠移動或單指輕點查看地形格子、座標、高度與地塊擁有狀態。

## 介面與精度

`TerrainPicker` 接收高度陣列／revision 與可選的 `ownsTile(index)`。`pick` 輸入 CSS client 座標與畫布矩形，不乘 DPR；也提供世界射線 `raycast`，方向會正規化。無交點、天空、畫布外、地圖外、零向量、非有限值及超過 maxDistance 回傳 null。

傳回 `TerrainPick`：世界 x/y/z、格子 x/z/index、地塊 x/z/index、owned 與射線距離。600×600 個 8 m 格子、5×5 地塊，座標零起算、index 按 z 行排列；世界邊界為 [-2400,2400)，避免最高邊界產生第 600 格。預設只擁有中央 (2,2)，查詢函式預留 Mirror 整合，沒有修改模擬資料。

先以 100 個 chunk 的實際高度包圍盒作 broad phase，再在候選區間按最多 2 m 步進；每次也停在高度格線和三角形對角線，以免略過近乎相切的窄山脊。符號變化區間二分 14 次，取所有候選的最近交點。`world/heightField.ts` 使用與地形 mesh 相同的三角形插值；這刻意不同於鏡頭既有的雙線性 heightAt，以對齊實際渲染面。

chunk bounds 只在 revision 改變時重算；ray、向量、命中物件與格子框 buffer 重用。傳回物件是暫借的，後續 pick 會改寫；交給非同步命令前請複製數值。

## 除錯顯示與手勢

- 8 m 格子白框每 2 m 取高度，抬高 0.2 m，貼合陡坡與三角形接縫。除錯框停用深度測試，方便觀察屋頂或水面下的地形；不代表選中了展示建築或水面。
- 滑鼠／筆 hover 每幀在相機更新後拾取，所以游標不動而鏡頭移動時也能跟上。座標文字最多每 200 ms 更新。
- 觸控只接受既有手勢系統判定的單指 tap。拖曳、第二根手指、取消、離開／失焦、隱藏頁面與 WebGL 中斷清掉標記；Esc 也能清除。
- 正常頁面不建立拾取預覽、框線或文字面板；僅除錯模式公開 `window.__webcityPick(clientX,clientY)`。輸入 API 可供未來工具使用。
