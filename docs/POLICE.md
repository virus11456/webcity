# M2-15 警察與犯罪

每棟活躍建築在每日結算依 GDD §10 計算：`crime = clamp(crime + 0.5 + unemployment × 2 - policeCoverage × 3, 0, 100)`。失業率取全市可工作人口的失業比例，沒有可工作人口時為零；警察覆蓋取 M2-14 的道路距離、容量及預算效果。施工、荒廢及燒毀建築不繼續累積。

crime 達 80 即顯示犯罪問題，原創盾牌驚嘆號加入既有單批圖示圖集；同棟仍由最接近荒廢期限的問題優先顯示。問題列表與檢視顯示當前犯罪狀態，即使剛跨過門檻、計時仍是零也可看到。持續 40 天高犯罪會依既有 GDD 問題規則使分區建築荒廢；降到 80 以下立即清除連續計時。公共設施不因這個計時自動荒廢。

警察局停用或斷路後，下一次日結不再獲得犯罪下降效果；不會在暫停時憑空重複扣減犯罪。Building.crimeUpdatedDay 確保重算與讀檔不重複計日，舊檔未設定 crime 視為 0；存檔驗證範圍及日期。Worker 先算人口與覆蓋，再算犯罪、問題與需求，結果以 building patches 送出。

單元測試驗證失業比例、警力公式、80 門檻、0/100 邊界、每天一次、停用警察局、40 天連續計時與中途改善、存讀檔及非法值。瀏覽器驗證真實 Worker 在同一 U 形路網中只降低連通範圍內的犯罪，另一段近距離但繞路過遠的住宅仍上升；三種裝置尺寸與手機橫式，使用 Chrome 觸控模擬。
