# M4-10 地塊擴張

工具列「購買土地」開啟俯視地形地圖：5×5 地塊、現有道路概略線及已購範圍。選地後顯示價格或拒絕原因，另按確認才發送 buyTile 指令；鄰接只計共用邊，不包含斜角、跨地圖邊緣。單格至少 44 px，可用觸控或鍵盤。手機橫式使用可捲动對話框。

Worker 以同一個 world/tiles.previewTile 再驗證有效座標、未持有、相鄰、里程碑、裝置上限與資金。第二塊 $50,000，之後逐塊 +$30,000；沙盒免費、全里程碑，但仍有鄰接與裝置上限。成功原子扣款並新增 ownedTiles，發 fundsChanged 與 tilesChanged；工具快取即時刷新，新地能立刻鋪路、分區、供水供電及放置建築。無需重新載入，也不自動搬移任何既有建築。

iPhone／iPod 以 4 塊為上限，iPad／桌機為 9。主執行緒啟動 SimClient 時從裝置識別取得 4／9，上下文中的每次 init／load 都送到 Worker，避免手動載入舊槽漏掉限制。WorldSnapshot.tileLimit 記錄當前上限；舊存檔預設 9，但正式 UI 讀檔會套用目前裝置限制。從九塊城市轉到 iPhone 時保留九塊既有土地，禁止繼續購地，不刪除玩家內容；此情況畫面可顯示已購數大於本機上限。桌機讀回則恢复九塊上限。

存檔拒絕越界、重複、空清單或超過九塊，接受已有但超過當前手機上限的城市。Worker 不依賴 DOM／navigator；地圖只在開啟時讀取快照，沒有每幀重建。地圖道路是節點間概略線，不能作為精細道路編輯預覽。設備上限不是多人安全權限，而是單機低記憶體保護。
