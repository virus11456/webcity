# M1-18 經濟系統

Worker 每完成 7 天，在人口、水電、問題結算後執行一次週結算。重複呼叫同週不重扣；日期 0 不結算。`stats.income/expenses` 是上次已結算週額，不是預估。建造、借款、提前還款改變現金，不混入稅收或日常維護費。

## 計算與交易

- 住宅只計 `housing.occupied`；商業、工業、辦公只計 `workers`。稅率使用比例（9% = 0.09），沿用 GDD 數值，沒有為了測試放大收入。空屋、空缺職位、施工／廢棄／燒毀不繳稅。
- active 公共建築按定義維護費；道路依實際長度／8m（高架 ×2）；電線／水管逐段累計長度。維護不按建造時的向上取整長度收費。垃圾焚化廠歸垃圾部門，避免因兼發電歸錯部門。未定義的分區建築維護費為零。
- 各稅種、各部門維護、小額分期本金及利息四捨五入至分，再加總。所有既有付費建造命令經 `chargeConstruction` 驗證與扣款後才改變世界；失敗不消耗 ID、不留下半條管線。既有免費分區與民間自動成長在負債時仍可用，市府付費建設禁止。拆除照既有退款／費用執行。
- 同時最多 3 筆貸款，允許同銀行多筆。採等額本金、剩餘本金計息：當週本金 = 剩餘本金／剩餘週數，週息 = 剩餘本金 × 年利率／52；末期清零。提前還清只繳剩餘本金，不收未來利息。借款後遇到下一個週界就扣首期，不按天折算。
- 稅率 1～29%；MS3 前住宅高低密度連動、商業高低密度連動。稅收下週反映，需求延續原有次日更新。稅率對幸福度留待後续幸福度系統。
- 部門預算 50～150%，MS1 解鎖。已存在的水電產能線性乘上預算，調整後立即刷新連線、供應及缺水電圖示；道路預算目前只影響維護。其他服務半徑／容量由各服務任務接入。
- 沙盒仍顯示週收支，但不扣款、不借貸、不破產。

## 破產

每週結算後，資金嚴格低於 −$10,000 才累計一週；達到門檻或回升時歸零。連續 4 週顯示警告，8 週停止時間與後續操作並顯示結束訊息。借款可救急，是否解除警告於下一週結算判定。重開城市走既有初始化流程；存讀檔尚屬 M1-24，此版結束畫面明確說明並提供重新開始。

## 協定與操作

`WorldSnapshot.economy` 記錄結算週、稅收／部門維護明細、貸款支出、連續負債週與狀態。新 `economy` 事件只傳小型財政資料；Mirror 防禦性複製，`readFinance()` 不複製地形。主執行緒用既有 `setTax/setBudget/takeLoan/repayLoan` 命令與 reqId，驗證非法名稱、NaN、越界值與鎖定狀態，沒有可寫入的除錯 API。

建造工具列的「財政」提供原型操作入口與可捲動的原生 dialog；正式共用面板、圖表與細部收支展示仍由 M1-19／M1-23 實作。稅率、借還款開局可操作；預算滑桿與大額貸款照 GDD 鎖定，正常模式須等後續里程碑卡實作才能解鎖，沒有提前發放解鎖或獎金。原生 modal 支援 Escape 與焦點限制，按鈕／滑桿 ≥44px，手機橫式可捲動。

## 驗證

- 單元測試覆蓋各稅種／等級、空屋與廢墟、維護分攤、水電預算產能、貸款 52 期本金守恆／提前清償／筆數上限／里程碑、負債原子交易、破產連續週重設、沙盒、Worker 驗證與 Mirror 複製。
- 黃金情境使用 seed 42 的可重現風場及受控平地／東側河岸，透過真實命令鋪三條 512m 小路與一條 256m 連接路，配置住宅／少量商業與工業、一座風力、一座抽水站、下游排放口、電線及水管。只固定測試地形，沒有注入人口、職位、現金、需求或建築，也沒有教學獎金。執行 28 天後人口 **741**、週稅收 **$637.20**、支出 **$389.28**、淨收入 **+$247.92**，水電污水全部供應、沒有廢棄建築。
- 黃金情境證明特定配置第 4 週轉盈，不代表任意劃區比例或低風場選址都能達成，也不代表已驗證 1,000／10,000 人規模的平衡目標。
- Playwright 三裝置驗證稅率連動、預算／大額貸款鎖定、真實借還款、7 日分期、三筆上限與 UI／Worker 同步；iPhone 另驗橫式。觸控為 Chrome 模擬，非 Safari 實機。
