# 核心工具（M0-06）

`src/core/` 不依賴其他應用層、DOM 或 Three.js。數學常數、浮點精度與演算法迭代上限屬於實作參數，不是遊戲平衡數值。所有公開函式都有 JSDoc。

| 模組           | 介面與約定                                                                                                                                                                                                                                                                                                                              |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rng.ts`       | `new Rng(seed)` 使用 mulberry32；safe integer seed 轉為 uint32；`next()` 回傳 `[0,1)`；`float(min,max)` 上界不含（相同界限回傳該值）；`int(min,max)` 上下界皆含，區間最多 2³² 個整數，拒絕取樣避免 modulo 偏差；`pick` 拒絕空陣列；`shuffle` 回傳副本。                                                                                 |
| `math.ts`      | `Vec2` 採世界平面的 `{x,z}`，與 `world/types.ts` 結構相容，避免反向依賴；向量運算與曲線取樣可傳入可重用 `out`，容許與輸入共用物件。                                                                                                                                                                                                     |
| `math.ts` 幾何 | 線段交點包含端點；共線重疊回傳沿第一線段方向遇到的第一點；無交點回傳 `null`。零長線段視為點。角度平行判斷採相對 epsilon，點重合採絕對 epsilon。                                                                                                                                                                                         |
| `math.ts` 貝茲 | 支援 3／4 控制點。長度以 de Casteljau 自適應細分，控制多邊形與弦長差限制總誤差（浮點捨入除外），預設精度 0.01 世界單位。最近點對每個自適應區間細化搜尋並比較端點，回傳曲線上的 `point`、`t`、`distance`；這是數值近似，不是解析解。細分最多 24 層，超出要求會拋錯。這些配置陣列的幾何查詢供工具／預計算使用，不應直接塞入每幀渲染迴圈。 |
| `events.ts`    | `EventBus<EventMap>` 同步按訂閱順序分派；`on`／`once` 回傳可重複呼叫的取消函式；重複註冊同一 callback 是獨立訂閱；分派取訂閱快照，訂閱變更於下一次發送生效。`once` 即使重入也只呼叫一次。`clear` 移除全部訂閱；listener 例外向呼叫端傳遞並中止當次分派。                                                                                |
| `grid.ts`      | `Grid(width,height,cellSize,origin)` 採 `index = z * width + x`；`cell`／`index` 越界拋錯；`worldToCell` 使用 floor，半開邊界外回傳 `null`；`cellCenter` 回傳中心；`neighbors` 回傳 4 鄰或 8 鄰有效索引，按列排序。                                                                                                                     |
| `spatial.ts`   | `SpatialHash<Id>(cellSize)` 索引點；`set` 插入或移動並複製位置；`delete`／`clear` 清除；`queryBox`／`queryRadius` 包含邊界且精確過濾候選。支援負座標、相同位置多個 ID；結果不保證空間排序。巨大稀疏查詢改掃已登錄點，避免遍歷大量空格。物件外形／道路範圍索引留給後續世界模組。                                                         |

## 驗證

- `npm run test:coverage` 跑完整單元測試，並量測全部 `src/core/**/*.ts`，未測核心檔案也納入。
- 每個核心檔案的 statements、branches、lines 至少 91%，functions 必須 100%；GitHub CI 執行同一命令並上傳 `coverage/`。
- 固定 mulberry32 已知序列、同 seed 混合操作重播、整數拒絕取樣及浮點上界測試。
- 幾何解析範例、端點／共線／零長／閉合與折返曲線，以及最近點與密集取樣參考值比對。
- 事件訂閱變更、巢狀發送、once、取消、clear 與錯誤傳遞；TypeScript 檢查事件／payload 型別。
- 非方形網格、負邊界與鄰格；空間索引以固定 seed 建立、移動、移除 200 點，50 組查詢比對逐筆掃描結果。
- `@vitest/coverage-v8` 僅為 devDependency，版本與 Vitest 同為 5.0.3；無新增 runtime 依賴或 UI 行為。
