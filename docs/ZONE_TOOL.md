# M1-08 分區工具與渲染

## 操作

選「開始鋪路」建立道路，再切換「分區」。正常模式開局可使用低密度住宅、低密度商業及工業區；高密度住宅／商業於 MS3、辦公區於 MS4 開放，選單會標示鎖頭及所需里程碑。

- **填滿**：點選空格，填滿同一 ZoneBlock 內四方向相連的空格，不穿越無效、已分區或占用格。取消分區時清除相連的同色格。
- **矩形框選**：拖曳世界 X/Z 軸對齊的矩形，選取格心落在範圍內的格子。
- **小／大筆刷**：半徑 1／3 格，連續移動使用掃掠圓形，快速拖曳不會留下事件取樣間隙。
- **取消分區**：分區種類選單中的橡皮擦選項，可搭配全部操作方式。
- 放開指標才提交一次交易；Escape、右鍵、雙指手勢或切換工具可取消尚未提交的選取。雙指仍由鏡頭控制器接管。
- 分區免費，暫停時仍可操作。探索模式保留已分區色塊、隱藏空格白框；展示街區保留原展示模式。

## 權威與效能

`world/zoning.ts` 為共用純驗證／轉換：Worker 重新檢查全部格子 ID、索引、合法性、整格土地所有權、分區解鎖及道路種類，整批成功後才更新權威狀態與發出 `zonesChanged`。輸入去重、重複塗色不產生無意義事件，最多一次 16,384 格；超過時請玩家分次操作。不信任主執行緒的篩選結果。

`world/zoneSelection.ts` 快取空間索引，互動不逐幀複製世界。`tools/zoneTool.ts` 管理草稿、待回覆狀態、錯誤與取消；世界格位改變會取消持有中的舊選取，避免提交失效 ID。網路／Worker timeout 不會自動重送。

`render/zones.ts` 使用 InstancedMesh；每幀最多建立一個 256 格批次，完整後才交換可見網格。地形高度紋理按照地表同一三角形插值，格子細分後貼地、抬高 0.3 m 避免 Z-fighting。白框以像素導數抗鋸齒；分區／預覽透明度為 ART 的 35%／60%。高度紋理、材質、幾何與 instance 資源在替換／dispose 時釋放。`?debug=1` 的 `__webcityZoneStats()` 可觀察實際鏡像分區碼計數、顯示 instance 數及重建狀態。

## 規格決定與目前範圍

- GDD「碎石路限低密度」解讀為 **RL／CL**，工業與辦公不視為低密度類別；清除允許任何仍合法的格子。
- 曲線產生的獨立 ZoneBlock 仍依區塊分別填滿，不跨越道路／區塊邊界。
- 目前城市還沒有可生長的權威建築。對已占用格改分區明確拒絕，避免破壞未實作的建築生命週期；GDD 的三天內拆除待 M1-12 建築生長整合。
- 高密度／辦公區的六色資料與指令已支援，正常遊戲里程碑進度尚待後續卡；單元測試以已解鎖及 sandbox 世界驗證六種類型。
- 道路／分區仍為可操作原型，尚無存檔；重新整理會清除。本卡不實作建築成長、人口、服務或市民通勤。
