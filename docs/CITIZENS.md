# M2-07 市民資料

`world/citizens.ts` 定義可序列化的 dense Struct-of-Arrays；每人 37 bytes（7 個 Int32、9 個 Uint8），移除時以最後一列補位，個人 ID 不變。容量倍增，記憶體測試包含空餘容量。家庭 ID 與個人 ID 各自遞增；0 代表沒有工作／學校。Worker 的 `CitizenSystem` 持有可重建的 ID 與家庭索引。

M1 v1 存檔原本的 `citizens: []` 仍可讀取，反序列化時轉成有版本的空表，Worker 初始化再依住宅的戶量建立個人。新檔保留全部個人欄位、生日相位、就學天數和最後結算日；不重抽工作。非法型別、長度、重複 ID、不存在的建築、非住宅住家、家庭跨住家及不合理屬性會被拒絕。外層 WCTY 版本仍為 1，市民表本身 `version: 1`。

## 人口與就業

住宅的五種戶量仍負責每日搬入／搬出，增減以整戶對照，保留未搬走的人。年齡／教育／勞動力／就業彙總改由實際居民產生，不再每天用人口的 55% 重建。新移入者按 20/10/55/15% 分為 6/15/32/68 歲，教育為 40/40/15/5%，兒童最高 0、青少年最高 1；同 seed 可重現。移入者的年內生日相位錯開，新生兒完整滿 30 天才加一歲。

19–64 歲且未在學者可工作。保留既有合格職位，新增居民依教育、距離和建築 ID 尋找空缺，允許高教育向下填缺。工業分三班（由固定個人 ID 決定），其他職務目前日班。公共服務及水電建築的職缺列於 `data/citizens.ts`，員工數不超過實際職缺；這張卡尚未用員工比例削減服務能力。新增學校優先保留原學生、再按距離分配空位；小學／高中／大學分別招收 6–12／13–18／19–24 歲且前一級已畢業者，累積 30 個有效就學日升一級。道路連通目前檢查建築的斷路狀態及學校半徑，M2-09 / M2-14 再接入路徑。

生日每 30 個財政日加一歲，65 歲退休，老人依 GDD 年死亡率判定，100 歲必定死亡。每 30 天成人家庭有 3% 生育率，但五人戶不再擴張；出生／死亡同步改變家庭大小，不會被下一次人口結算復活。當日出生、死亡與遷入、遷出分開計算。死亡者從活動表移除；遺體與靈車待 M4-08 的殯葬佇列。這張卡不產生可見交通，也不更動財政與日夜時鐘。

## 驗證與成本

單元測試涵蓋舊檔轉換、存讀檔一致、穩定就業、容量和資格、退休、生死、學校拆除、容量不足、壓縮移除。十萬居民 SoA 精確配置 3,700,000 bytes；另有 Worker 可重建索引，不會寫入存檔。1000 住宅／1000 工業的十萬人口案例量測 35 個日更新（含生日及死亡），本機 p95 約 6.8 ms；單純生命週期 p95 約 3.3 ms。測試的 `<10 ms` 為本機 p95，並非手機實測或所有結構重建的最壞上限。大量移入、新工作／學校開放及跨年齡層重新媒合屬結構更新，成本與一般日更新分開。
