# M2-22 城市資訊圖層

工具列的「資訊圖層」開啟地價視圖，選單可切換電力、供水、污水處理、地價、地面污染、水污染、噪音、犯罪、健康、教育、幸福度、火災風險、人口密度、肥沃度、森林、礦產、石油、風力共 18 種。交通視圖由相依此卡的 M2-12 接續；垃圾、行政區、大眾運輸仍屬 M4，未提供假資料選項。按「關閉圖層」或 Esc 回到正常畫面；切到建造工具也會關閉圖層，避免熱圖與地下水管等專用模式混淆。

色階沿用 ART §2.5 綠→黃→紅，每種圖例明確標出數值方向與單位；灰色代表無對應資料。高地價、健康、教育、幸福度與供應是綠色，高污染、噪音、犯罪與火災風險是紅色。人口密度以 1,500 人／公頃為色階上限（超過仍保留原世界數值），資源／風力是濃度或強度而非服務好壞。火災風險以未被消防覆蓋比例呈現，正在燃燒直接列最高風險。

地價／污染／噪音直接讀 Worker 場；水污染只在實際水域上顯示，建築則顯示自身飲用水或取水污染。供電、供水、排污使用各棟實際 flags；供水與污水視圖另啟用既有半透明地面、地下管線與範圍顯示。健康使用住戶平均，教育用居民／在職員工平均。這些離散建築數值在地面 24 m 內取附近樣本平均，圖例清楚標示，沒有把鄰近水管當作已供水。資源讀真實地形場，風力使用與風機相同的 seeded windAt。

`world/infoViews.ts` 純衍生資料，不修改世界；主執行緒接收快照、建築／環境／地形增量事件。`render/overlays.ts` 使用 300×300 地形 DataTexture、600×600 設施占地色彩遮罩，以及分區建築原有 per-instance 顏色。後者沿用有界重建佇列，LOD 與新模型皆繼承當前色彩。設施已按材質合併的幾何以占地遮罩上色，避免為資訊圖層拆開繪製批次。場景其他物件降低飽和；材質 hook 接在既有地形／水面／建築／CSM 後，防止重複注入，關閉切回原色。資料改變最多每 250 ms 更新，不在每幀重建資料或貼圖。

面板遵守 44 px 操作尺寸與 safe area，手機直橫式使用同一選單；開啟時收起建造說明及人口小窗以留出地圖。純 DOM 控制不直接操作 Three，回呼由 game.ts 串接。生命週期回收事件、ResizeObserver、材質 hook 及貼圖。未新增依賴或外部素材。

測試包括所有視圖的數值方向、缺少資料、供應旗標、水域遮罩、權威資料不變、材質鏈重掛／不重複注入、增量貼圖、per-instance 改色與恢復，以及三裝置逐一切換 18 種模式、關閉／Esc、手機橫式與 WebGL 錯誤檢查。截圖位於 screenshots/m2-22/；Chrome viewport／觸控模擬，非 iOS Safari 實機。
