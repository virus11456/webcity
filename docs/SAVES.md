# 城市存讀檔（M1-24）

提供 10 個手動槽及獨立自動槽。手動覆寫有第二次確認；存檔清單顯示城市名、人口、遊戲日、儲存時間與縮圖。每五分鐘及切到背景時自動儲存；瀏覽器突然被作業系統終止仍可能來不及完成最後一次非同步寫入，保留最近成功的槽。

格式為 `WCTY` 四位元組、little-endian uint32 版本、gzip 壓縮的 MessagePack。Float32Array / Int32Array 使用自訂 little-endian extension，Uint8Array 為 MessagePack binary。固定 key 排序與省略 undefined 保證同一快照的存→讀→存二進位一致。

Worker 原子取得快照及對應 metadata。壓縮期間城市可繼續運行；載入期間暫停接收修改指令，完整解壓、版本、型別、數值與拓樸檢查通過後才替換世界。損壞／不支援版本不覆寫現有城市。v1 是目前唯一發布的檔頭版本，但已有缺少後續可選欄位的歷史檔；migrations 會補齊居民、行程、公共服務、教學及災害等缺省結構。未來不相容版本需保留舊版讀取與遷移。

IndexedDB 的 metadata / data 寫入使用同一交易，空間不足不會只覆寫一半。縮圖失敗仍可存城市。載入使用明確選取的槽重新建立 Worker 和與城市相同 seed／地圖的 renderer；一般重新整理不會自動覆寫手動槽。資料只保存在目前瀏覽器，不是雲端同步。

新增 runtime 依賴 `@msgpack/msgpack@3.1.3` 與 `idb@8.0.4`，均為 TECH §1 原指定套件。Worker 進入點作為序列化轉接層，可注入 save codec；模擬系統與 CommandDispatcher 本身仍不依賴儲存／瀏覽器 API。UI 透過 game 提供的 SaveActions 操作，不直接存取 IndexedDB。

驗證：型別陣列與二進位往返、恢復後繼續同一個 tick、損壞／新版本／無效拓樸拒絕、載入中指令拒絕與失敗保留原城；三裝置實際建城→存檔→重新整理→讀檔，逐項比對人口、建築、分區與資金；背景事件驅動自動槽（可見性以明確 fixture 觸發，城市快照來自真實 Worker）。

API 依據：[MessagePack 官方實作](https://github.com/msgpack/msgpack-javascript)、[idb 官方文件](https://github.com/jakearchibald/idb)。

存檔採語意一致的正規格式：數字 `-0` 轉為 `0`，未設定的可選 `undefined` 欄位省略。實際城市數值、地形 typed arrays 與下一步模擬結果不變；整合 E2E 比較城市時正規化這兩類 JavaScript 表示差異。

## M5-07 歷史存檔回歸

保留 M1、M2 居民系統與 M5 三個 commit 的固定 `.wcity` 樣本，來源、SHA-256、產生方式與涵蓋範圍見 [fixtures 說明](../tests/fixtures/saves/README.md)。三個樣本合計約 23 KB；地形為明確人工平地，保存道路、住宅六位居民、貸款及稅率。不能重新產生樣本來掩蓋不相容。

專用單元案例逐檔確認格式、舊欄位確實缺省、居民轉換／ID 保留、資產與資金保留、存讀往返及續跑一致，並檢查版本 1 到最新版都有樣本。GitHub Actions 獨立 `Archived save compatibility` 工作執行此案例，既有完整驗證工作不變。三裝置瀏覽器回歸另載入最早的 M1 檔，經實際 Worker 轉換後保存到新槽、重新載入，再運行遊戲日曆。

## M5-08 檔案備份與還原

在城市中的「存檔／讀檔」按「匯出目前城市」，等待備份準備好，再按「下載備份」取得 `WebCity-城市名.wcity`。瀏覽器支援檔案分享時另提供「分享／儲存到檔案」，可由系統分享介面選擇儲存位置；取消分享後仍可下載。非同步快照完成後的第二次點選保留觸控使用者手勢。關閉面板或重新產生備份才釋放下載連結。匯出不覆寫任何本機存檔槽。

還原時在目標手動槽按「匯入檔案」，選取 `.wcity` 後確認；已有城市的槽會明示「確認匯入並覆寫」，也可取消。檔案完整驗證通過後才原子寫入該槽，之後按該槽「讀取」開啟；匯入本身不替換目前遊玩的城市，也不覆寫自動槽。匯入檔案沒有縮圖，首次正常儲存後會更新。這是手動備份／跨裝置搬移，不是雲端同步。

選檔先限制 9 bytes～64 MiB，再由獨立 module Worker 執行既有完整解壓、版本、結構與遷移檢查；驗證最多 30 秒，結束或失敗均終止 Worker。驗證 Worker 不建立 Simulation，也不向遊戲 Worker 發修改指令；IndexedDB 仍由 save/controller 單一交易寫入。損壞、新版本、超限、驗證逾時或空間不足不應破壞原槽；測試涵蓋無效檔案、取消、配額失敗及重試。格式仍為 v1，沒有新增 runtime 依賴。

三裝置瀏覽器測試涵蓋真實下載內容、原生選檔入口、確認／取消、錯誤檔案保護、匯入與讀回、分享取消與 URL 清理、44px 按鈕及 iPhone 橫式。分享測試只模擬作業系統 API 邊界，並非 iOS 原生分享面板驗證。Safari 真機仍需實際走過「分享／儲存到檔案」→「儲存到檔案」，再由匯入選檔器取回備份，故整張 M5-08 尚不勾選完成。
