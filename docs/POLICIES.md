# 政策（M4-05）

工具列「政策」開啟面板，MS4 解鎖，沙盒直接使用。適用範圍可選全市或行政區；行政區提供「繼承全市／開啟／關閉」。覆寫設定存入該區，移動區界立即重新計算所屬建築，刪區後恢復全市設定。相同政策只生效、收費一次；費用按實際入住戶數，財政面板獨立列出上週政策費用。政策面板顯示本週預估費用與全市每日垃圾產量。

| 政策         | 實際行為                                                                                                                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 禁止高樓     | 最高 Lv3、最多 4 層。現有高樓調降等級並重算容量，可能造成住戶搬出；關閉後恢復正常升級，未直接升回舊等級。受限建築使用有樓層上限的原創程序模型，所有 LOD 遵守上限。                                        |
| 吸菸禁令     | 有效健康為原始健康 ×1.1，最高 100；健康／生病統計採有效值，原始健康不反覆乘算。幸福度 −2。                                                                                                                |
| 回收計畫     | 每棟實際每日垃圾產量 ×0.8，垃圾存量與上次產生日持久保存。同一天刷新或讀檔不重複產生。垃圾車收集由 M4-07 接續。                                                                                            |
| 免費公車     | 上車站點所屬政策決定票價；免費時實際上車不產生票款。居民出發位置的搭乘意願從基準 70% 提升為 91%（×1.3），以居民 ID 決定性抽樣；需有可步行抵達的實體公車路線，不保證乘客數恰好增加 30%。地鐵與電車不套用。 |
| 重型車輛禁令 | 中心線進入禁行區的一般道路整段排除於貨運 A*，高速公路及區域道路除外。行進中貨車若後續路徑違規，保留實際位置與貨物等待重新尋路；無可行道路時不假造送達。一般汽車與公共服務車不受限。                       |
| 節能／節水   | 真實電網／管網需求乘以 0.85；節水也降低相同比例污水需求。                                                                                                                                                 |
| 寵物禁令     | 區內公園維護 ×0.9，住戶幸福度 −1。                                                                                                                                                                        |
| 教育推廣     | 區內住戶已入學居民的畢業時間為 ceil(原天數／1.1)，不憑空增加學位或免除道路連接要求。                                                                                                                      |
| 高科技住宅   | 住宅升級地價門檻 −10，最低 0；不改變就業建築的門檻。                                                                                                                                                      |
| 小型商業優惠 | CL 地塊的有效需求 +10（影響實際生長嘗試），CL 稅收 ×0.9，CH 不受影響。共用 C 需求條仍顯示全市基礎值。                                                                                                     |

所有平衡值來源為 `data/policies.ts` 與 `data/transit.ts`。政策費用不受服務預算滑桿折扣。工業特化仍是 M4-06 的獨立任務。
