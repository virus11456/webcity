# M1-11 建築事件渲染

## 看得到的變更

建築工坊新增「街區施工展示」（`?district=1`）。四棟住宅、工廠與辦公建築共用一個場景，可播放地基、結構、外牆收尾、完工，另可查看荒廢變灰、拆除下沉與塵土、重新放置的彈跳效果。展示用事件走城市相同的 `BuildingRenderer`，不寫入 Worker、資金或存檔。頁面明確標示展示性質；分區自動成長仍由 M1-12 實作。

「展示 5,000 棟」遍歷 164 種合法分區／等級／占地，使用 5,000 個不同種子，驗證大量建築及遠景。拖曳旋轉、滾輪縮放、雙指平移／縮放。手機直、橫式與平板均保留 44px 控件、12px 以上文字。

## 城市整合與權威

`game.ts` 建立 renderer，初始化時只複製 `mirror.readBuildings()`，再訂閱 SimClient 的 `ready`、`buildingsChanged` 與道路地形變更。進入實際建造模式時顯示權威建築，返回展示城市則隱藏；原有裝飾街區不會混入模擬。HMR 會取消訂閱並釋放資源。

新增與部分更新合併到 renderer 自己的只讀副本，依 ID 合併待處理工作；移除未知 ID、更新不存在 ID 均不建立幽靈物件。重新載入 snapshot 會清掉舊場景及未完成動畫。事件與原始 Building 不被渲染器修改。

M1-12 的施工協定約定：`state === 'construction'` 時，`stateTimer` 表示已施工的遊戲天數，進度為 `stateTimer / GROWTH.constructionDays`，限制在 0～1；`active` 事件才代表權威完工。相鄰進度更新以 0.24 秒平滑過渡；沒有新事件就停止在已知進度，不按實際時間自行蓋完。`active` 立即撤去鷹架，轉為完成建築。展示播放的 12 秒僅用於展示事件，不是遊戲施工時間。

## 批次、細節與資源

- 新增與更新每幀至多 24 筆，並以 2ms 軟預算提前結束。單個小型模型是最小工作單位，不能在模型生成的中途讓出執行緒。
- 完整幾何依 position／normal／color／UV 內容雜湊共用 InstancedMesh。命中雜湊後仍比對內容，避免碰撞錯配。池從 8 個 slot 倍增，保留矩陣、顏色及狀態；移除以最後 slot 補洞。最後一個實例離開時釋放該幾何池。
- 以 450m 為基準（直式依相機寬高比補償取景距離）的最近 16 棟採完整模型，其中同時最多 4 棟保留逐層結構、外牆、線框鷹架與大型起重機。每 0.2 秒重新選擇，單次最多建立一個近景模型，先退休再取得，避免鏡頭旅行累積幾何。
- 其餘建築以同一個確定性生成器取得體量，跳過細部三角形建立。遠景用共用方體 InstancedMesh 保留各棟的基座、塔身、退縮、實際樓層高度、牆色與位置；暫不保留窗戶、屋頂、煙囪與天線細節。遠景施工用共用地基、線框與逐漸揭露的體量。這是本卡效能目標所需的有界細節策略，精細 LOD、淡入過渡與更多同屏細節仍留給 M3。
- 所有完成近景共用一個材質與同一對窗戶 Atlas；遠景共用另一個無貼圖材質。灰化與燒黑以 per-instance 狀態控制，不複製材質。施工／塵土另用專用材質。大型展示增長過的共用池保留容量以便重用；退出頁面則全部 dispose。
- 放置彈跳 0.25 秒，拆除下沉 0.4 秒；最多 96 顆原創方塊塵土粒子，避免大量事件造成特效爆量。拆除動畫只保留渲染副本，不延後 Worker 的實際移除。
- CityRenderer 的材質註冊支援在 CSM 初始化／畫質切換後重裝建築狀態 shader，也提供註銷，避免已拆除施工材質被陰影管理器保留。context 恢復後由 Three.js 重新上傳既有資源。

## 驗證與界線

單元測試涵蓋 pool 擴容／補洞、幾何雜湊、164 種組合的遠近體量一致、事件合併與不可變性、權威進度、拆除後 ID 重用、模型共用、5,000 棟分幀建立及清除。

Playwright 驗證三裝置四階段畫面、播放暫停、荒廢／拆除／重建、反覆重建資源穩定、手機橫式與 5,000 棟 draw call。效能數字是桌機 Chrome 在獨立建築展示的量測，包含地面、道路及陰影繪製，並非完整模擬城市或 iPhone Safari 的效能保證。城市的道路／分區／拆除及 PWA 流程另跑回歸。

服務建築專用模型仍屬後續任務；本卡只渲染六種 zoned 建築，其他 kind 不會被誤畫成住宅。人口成長、工人、動態車輛、路線及上下班仍未在此卡實作。

## 本次結果（2026-10-06）

- lint、typecheck、532 項單元測試、正式 build 通過。
- 完整回歸初跑 61 通過、11 個裝置不適用略過；三個新增案例在 GPU 共用池首次配置前取到較小基準而失敗。改為比較等價的暖機重建後，三裝置補跑全部通過，加上大量建築案例共 4 通過、2 略過。合計 64 個不同 E2E 案例通過。
- 桌機 Chrome、1440×900、DPR 上限 1.5、單張陰影：5,000 棟 / 9,145 個遠景體量，含陰影 **3 次 draw call、219,482 三角形**；穩定 300 幀取樣 **59.995 FPS**。
- 分幀載入約 3.48 秒，全部拆除約 3.87 秒；事件處理單幀最高 2ms，量測期間沒有超過 50ms 的主執行緒長任務。載入／拆除是漸進處理，不是一次凍結數秒。
- 三裝置四階段、荒廢、拆除、重建與手機橫式截圖見 `docs/screenshots/m1-11/`。PWA 離線重載與 context 恢復亦有檢查。
