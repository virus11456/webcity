# M4-06 自然資源與工業特化

行政區面板提供一般工業、林業、農業、礦業、石油。MS6 解鎖（沙盒直接開放），Worker 驗證設定；繪製、轉讓、刪除行政區均更新區內工業。資源資訊圖層沿用森林、肥沃度、礦石、石油四張 300×300 raster；建築以其位置所在的 16 m 格取樣，和圖層一致。

特化每日產量 = 實際在職人數 × 0.5 × 當地資源值 / 255；沒有資源不產出、停用或火災中不生產、每日只結算一次。倉庫沿用貨運容量及上限。四類資源不耗竭（本卡未規定耗竭／再生速率）。教育職缺比例皆為 75%／20%／5%／0%，使用最大餘數分配，總職位仍由工業等級／地塊決定。每職位污染依林／農／礦／油分別為 0.1／0／0.8／1.2；噪音沿用工業規則。

特化產出為木材／農產／礦石／原油，只出口、不直接補充商店商品。一般工業仍產製成品；本卡未新增原料加工配方。原料由現有權威貨運系統派出可見貨車，須經道路及對外高速公路抵達邊界才增加出口統計，適用重型車禁令與斷路停留／恢復。Shipment.commodity 保存原料種類，已出發貨車不因工廠轉型改變貨物；轉型清空厂內庫存並記入 cargo.lost，面板事先提示。出口累計目前仍是所有貨種的總數。

四類專屬原創程序造型為木料堆與林木、農作行列與穀倉、礦石堆與吊架、抽油機與油槽；近景詳細幾何和遠景 InstancedMesh 共用輪廓，轉型即重建、施工動畫沿用相同輪廓。所有顏色源於 palette，沒有新增外部素材或 runtime 依賴。

儲存保留 District.industry、Building.industry 與 Shipment.commodity；舊存檔缺欄位視為一般工業，讀檔時依行政區重新核對建築類別。拒絕無效特化、非工業建築帶特化、原料送往商店的損壞存檔。

驗證：新增四類資源／低教育職位／不同污染／LOD 輪廓、解鎖、轉型庫存、存檔驗證，以及實際貨車出口、不供應商店、缺工停產、斷開出口測試。三裝置 E2E 以正常 UI 設定四類特化，切換四張資源圖層、儲存重載；手機橫式再次轉型確認可操作。驗證結果見 TASKS.md。
