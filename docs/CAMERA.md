# RTS 鏡頭（M0-08）

`render/camera.ts` 的 `RtsCamera` 管理 Three.js 相機，輸入為地形高度函式、地圖邊界及可選初始狀態。`CityRenderer` 已在每幀更新鏡頭，再同步光照焦點與天空位置。M0-10 已接入真實地形 `heightAt` 與以原點為中心的 4.8 km 邊界；市中心、河岸、全景按鈕透過 `main.ts` 呼叫 `flyTo`。

本任務完成鏡頭模型與程式 API。M0-09 已接入滑鼠／鍵盤、雙指捏合、手勢分流與依距離縮放的輸入速度；操作方式見 `INPUT.md`。

| 介面                            | 單位與行為                                                                                                                                               |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pan(dx, dz)`                   | 世界平面公尺，設定目標焦點位移。                                                                                                                         |
| `rotate(delta)`                 | 弧度，沿最短角度差平滑旋轉。                                                                                                                             |
| `tilt(delta)`                   | 弧度，設定仰角；先限制合法範圍。                                                                                                                         |
| `zoom(factor, screenAnchor?)`   | 小於 1 放大、大於 1 拉遠；anchor 為 NDC `{x,y}`，x 向右、y 向上，畫布左上角為 `(-1,1)`。輸入層須由 CSS 座標轉換，不使用 backing-buffer 尺寸。            |
| `flyTo({x,z}, distance)`        | 一秒 smoothstep 飛到限制後的焦點與距離；新指令可中斷飛行。                                                                                               |
| `update(deltaSeconds)`          | 以秒推進，0 僅更新地形／姿態。背景暫停由 renderer 排除，回到前景不補算整段時間。                                                                         |
| `groundAt(ndc, out)`            | 對高度場作 8 m 步進與二分細化，寫入重用 Vector3；無交點（天空或超出 far）回傳 false。這是鏡頭縮放用取樣，不取代 M0-12 的地形拾取（物件選取待後續工具）。 |
| `resize(aspect)`                | 更新投影矩陣並取消舊的畫面錨點。                                                                                                                         |
| `copyFocus(out)`、`readState()` | 前者重用向量供光照每幀讀取；後者回傳副本供 UI／除錯，避免每幀使用。                                                                                      |

## 限制與演算法

- FOV 45°、距離 20–4000 m、仰角最低 15°；近距離最大 60°，隨距離線性增至 4000 m 時的 89°。ART 僅指定「越遠允許越大仰角」，60° 近距離上限是本次採用的具體補充。
- 阻尼 0.15 按 60 FPS 定義，使用 `1 - (1 - 0.15)^(dt * 60)` 達成跨幀率一致。
- 焦點限制於傳入邊界，高度由地形提供；相機位置至少高於該處地形 5 m。避碰上抬可能使實際視線距離大於名義 orbit 距離，地形安全優先。
- 縮放先取游標／捏合中心下的世界點，每幀用有限差分 Newton 修正水平焦點，使該點投影保持固定；平地、斜坡、丘陵都有逐幀回歸測試。向量和計算暫存物件重用。
- 地圖邊界優先於縮放錨點；在無法同時滿足的位置允許錨點偏移。天空錨點改為一般以焦點縮放；高度場步進不是任意尖銳／不連續表面的精確求交。
- 地形函式須回傳有限高度，取樣超出邊界時以邊界座標取高。所有設定集中於 `src/data/rendering.ts` 的 `CAMERA`。

## 除錯與驗證

只有 `?debug=1` 會公開 `window.__webcityCamera`，可從開發者工具呼叫上述鏡頭 API。它不控制模擬世界；開發熱更新時移除。一般頁面不公開此介面。

- 265 項單元測試全數通過；鏡頭測試涵蓋邊界、角度、距離、地形避碰、15／30／60／120 FPS 下的一秒飛行、飛行中斷、NDC 錨點、無命中與錯誤輸入。
- 21 項 E2E 在 iPhone 15、iPad Pro 11、Desktop 通過，包括鏡頭 API 動畫、30 個繪製幀的縮放錨點誤差小於 0.0001 NDC、旋轉尺寸與既有渲染／PWA 流程。
- `docs/screenshots/m0-08/` 保存操作後的三裝置與 iPhone 橫式截圖，採中畫質。這是桌機 Chromium 裝置模擬，正式手勢及 iOS 實機驗證仍屬後續工作。
