# 住宅模型（M3-10）

交付 60 個 RL（5 級 × 1×1／1×2／2×1／2×2 × 3 變化）與 30 個 RH（5 級 × 2×2／3×3／4×4 × 2 變化）。每檔含 LOD0／1／2，命名 `bld_{zone}_l{level}_{w}x{d}_{variant}.{hash}.glb`。90 個檔案共約 2.2 MB，內容雜湊載入，Meshopt 幾何＋KTX2 色彩／自發光 atlas；各分區材質在遊戲中共用。

模型以原創參數化幾何離線製作，不採用外部遊戲素材或宣稱由 Blender 手工建模。使用既有確定性建築體量，住宅增加煙囪、矮籬、門階；公寓增加入口雨棚、支柱與階梯。近景保留屋頂、陽台、花園與設備，中景保留體量和相同樓層窗格，遠景符合 12／24 triangles 預算。地面正面中央為原點、+Z 朝道路，套用到城市仍使用原來朝向轉換。

`npm run assets:models -- res` 使用現有 Vite 編譯離線工具，需要 M3-01 的 KTX CLI。每個分區只壓縮一次 atlas，所有模型使用相同像素；recipes JSON 保留每個檔案的參數、三段面數、大小與 hash 路徑。正常遊戲 build 不需 KTX CLI。新增套件皆為現有 glTF CLI 使用的開發依賴，沒有新 runtime 套件。

`CatalogAssets` 複用 M3-01 載入器，還原 Meshopt quantization 的節點變換後交給既有 instanced 建築池。載入期間／失敗／未列入的地塊組合使用程序幾何，鏡頭離開再返回可重試；成功後在既有分幀細節預算内替換。原本的施工進度、建築狀態、夜窗與資訊圖層 shader 保留。M3-14 接續全城 LOD 整合，本卡把三段素材先備齊。

工坊 `?asset-gallery=1` 可選每個模型；URL 可指定 `model=bld_rl_l2_2x2_03`。驗證包含所有 90 GLB 的命名／hash／壓縮／貼圖／材質／面數、原點、確定性映射，以及真實城市中的成功載入與 503 失敗替代顯示。視覺測試使用明確的 90 棟展示存檔，不宣稱這是自然成長的經營城市。

驗證：lint、typecheck、production build 通過；完整單元測試 903 項（單 worker、15 秒測試上限），6 項三裝置 Playwright 測試通過，涵蓋 503 備援、恢復載入、原有素材離線快取及模型選單。已檢視 iPhone 直／橫式、iPad、Desktop 截圖；手機鏡頭依較小視角取景，避免寬住宅裁切。裝置驗證為本機 Chrome viewport 模擬，非 iOS 實機。城市近景仍沿用 16 棟細節預算，M3-14 再接全城 LOD。
