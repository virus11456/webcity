# M1-17 建築問題與廢棄

## 權威狀態

`sim/systems/problems.ts` 在 Worker 讀取供電、供水／排污 flags、道路斷線及就業結果。只對已完工的分區建築套用五種問題：缺電／缺水 20 天，污水／沒道路／缺工（工作填補率嚴格小於 25%）30 天。住宅的水務需求沿用實際入住戶數；空屋沒有水務需求。尚在施工或玩家放置的設施不因這套住宅／企業廢棄規則消失。

`problemSinceTick` 為各問題首次觀測的絕對 tick；`problemTimers` 是持續遊戲天數，可含小數。每日結算按人口 → 電力 → 水務 → 問題 → 必要的人口與水電重算 → 需求執行，合併同 ID patch 後才送到鏡像。問題期限在日結及建造／拆除等權威刷新時檢查；滿期限後的下一次刷新會廢棄。若沒有其他操作，非整日開始的問題會在滿期限後下一次日結廢棄，不會提早。

建造、拆除、接管及施工完成也刷新問題；暫停中恢復服務會立即清空該問題起始 tick 和計時器，重複刷新不累加時間。其他仍存在的問題繼續計時。沒道路的來源沿用 M1-09 的 frontage 與 `roadDisconnectedDay`；道路修復立即清除。施工期不累積服務缺乏時間，完工後開始計時。

廢棄時記錄 `abandonedAtTick` 並保留觸發問題計時。重新核算住宅／工作容量，清掉入住戶、居民、職位與員工；人口搬出統計同步，工作配對不再包含該建築。廢棄後供電恢復不會自動復活。`stateTimer` 改表示廢棄天數。施工成長系統於滿 60 天移除廢棄／燒毀建築，清空所有占用格但保留分區、不扣款；符合既有成長條件可重新施工。手動拆除沿用既有每格 $100 清理費及沙盒免付費規則。

## 顯示與操作

- `render/icons.ts` 使用原創 Canvas Atlas 與 Instanced Billboard，六個符號不依賴字型、Emoji 或外部素材；一批、一個 draw call，上限 300 個。
- 每棟僅顯示距離廢棄期限最近的問題；同期限依缺電、缺水、污水、道路、工人排序；廢棄／燒毀顯示灰色房屋叉號。
- 建築生成器提供實際屋頂高度與地塊中心，圖示放在屋頂上方 7m。固定 30 CSS px、輕微上下浮動 2px，深色底及白色線條。
- 相機距離超過 1500m、鏡頭後方及畫面外不顯示。採近景優先、38px 螢幕間距排除重疊；不遮擋點選，不對圖示加互動命中區。
- 道路工具列保留可展開的「問題建築」入口；「查看問題建築」依 ID 輪巡問題建築並移動鏡頭，列出全部問題及已持續／上限天數。這是 M1-17 的簡易問題檢視，完整選取面板仍屬 M1-22。
- 每幀重用候選陣列、向量、TypedArray；圖集、材質與幾何在 dispose 時各釋放一次。快取更新只由已確認 Worker 事件觸發，不修改權威世界。

## 範圍與相容性

新增 Building 的兩個 optional 欄位，沿用現有 snapshot／BuildingPatch 傳輸，不新增 debug 寫入或 runtime 套件。目前城市尚無存檔功能（M1-24），因此不宣稱存檔遷移已完成。讀入缺少起始 tick 的現有記錄時以既有計時回推。

本卡不實作垃圾、犯罪、疾病、火災原因、河水污染、稅收或周邊地價懲罰。廢棄外觀沿用 M1-11 已有灰化與熄燈；細部破窗貼圖留待美術精修。缺工讀取 M1-13 聚合工作配對，並不代表個別市民或車流路徑已實作。

## 驗證

單元測試涵蓋五種獨立期限、非整日起始、同日重複更新、修復／再次斷線、同時多問題、25% 邊界、空屋、施工／設施豁免、搬出與鏡像合併、60 天倒塌及占用釋放；渲染測試涵蓋健康→部分 patch→缺電→修復→廢棄→刪除、距離與鏡後隱藏、300 上限、重疊排除和資源釋放。

三裝置 E2E 透過實際道路／分區／水電工具建立受服務住宅，驗證修復計時歸零後拆除電廠，顯示缺電圖示、問題檢視與遠距隱藏；播放時間後驗證廢棄與居民歸零，再播放 60 天確認原建築消失。觸控為 Chrome 模擬，不代表 iOS Safari 實機。截圖與最終測試結果見 PR。
