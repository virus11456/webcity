# M2-19 公園與植樹

公共服務建造目錄新增小公園、兒童遊樂場、廣場、大公園與植樹筆刷。公園沿用地形、已購土地、解鎖、道路臨接及占用檢查；樹木可種在不臨道路的合法陸地。費用與維護沿用 GDD §10.1。模型為程式生成的原創步道、長椅、遊具、水池與錐形樹冠；植樹採共享幾何的兩批 InstancedMesh，不逐樹建立模型或繪製呼叫。

筆刷半徑 16 m、格距 8 m，每次確認最多 128 棵，全城最多 4,000 棵。單指／滑鼠拖曳選取，確認後 Worker 一次驗證並扣款；取消及雙指手勢清除尚未確認的筆畫。已有樹木、道路、建築、未購土地或不合適地形會跳過，費用僅計算可種的樹。資金不足時整筆不成立，重複筆畫不會再次扣款。

樹木以 `kind: park`、`defId: tree` 的建築記錄儲存，保留 ID、種植日與實付費用，沿用存檔、選取、拆除與退款。每棵保留 1×1 格，避免反覆種植重疊；不提供職缺，不形成電力傳導節點。四種公園也不需要水電與職缺即可提供本卡的休憩加成。

公園／樹木從占地中心向外線性衰減，加成與半徑乘公園預算。樹木加成總量最多 +10，依 GDD 各公園的個別半徑、加成疊加；只計入啟用、使用中、未失火的來源。目前地價為基礎 10 加休憩加成、上限 100，16 m 格網取樣；M2-20 接入污染、噪音、臨水、公共服務及平滑。樹木降噪也由 M2-20 接入，不在本卡假稱已完成。

建築檢視新增地價與公園／樹木加成，放置、預算、停用、拆除即時更新。公園建造預覽是徑向影響範圍，並非公共服務的道路距離；實際計算以占地中心為準。

測試涵蓋四種公園、地價提高與加成移除、樹木格距與筆畫上限、資金不足原子失敗、占用、地形、土地、重複種植及存檔。三裝置 E2E 透過真實 Worker 建造四種公園、取消筆畫、拖曳種植並讀取地價；iPhone 另驗證橫式。截圖位於 `screenshots/m2-19/`。

M2-20 已接入完整環境地價、平滑及樹木降噪，以上 M2-19 單卡紀錄保留；目前規則見 ENVIRONMENT.md。
