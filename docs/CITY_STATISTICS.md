# 城市統計（M4-16）

底部「城市統計」開啟可捲動面板，支援手機橫直式、鍵盤與觸控。顯示人口、入住戶、當日搬入搬出；四組年齡、教育人数與比例；可就業／已就業／待業、失業率、工作與空缺；道路車數、加權平均速度、相對速限、壅塞路段。

年齡與教育加總 CitizenSystem 寫入住宅的實際人口摘要，並非固定人口百分比。失業率分母為可就業人口（排除不在勞動市場的居民），為零時顯示 —。人口與就業在日結及結構變更刷新。

交通讀取 Worker 的完整 roadTraffic 事件，排除行人，與渲染畫質的車輛上限無關；速率以每路段當前車數加權。空路不參與平均、無車顯示 —；壅塞指有車且車速／速限 <40%。車數不是每小時流量。載入從存檔路徑、車速重建，刪路即移除舊樣本。

只有面板開啟時更新 DOM；不複製地形、不掃描每位居民、不新增套件或存檔欄位。統計是唯讀操作。
