# M4-09 里程碑

Worker 在人口遷入更新後與每個運行 tick 檢查 GDD §14 全部 11 級門檻。每個未領級別依序加入 `unlocked` 並立即發放獎金，同一次跨多級會獲得每級獎金。獎金為一次性現金，不混入每週稅收。人口下降不撤銷解鎖；沙盒全解鎖但不發放獎金。

每級透過 `milestone` 事件同步主執行緒，建造目錄（道路、住宅、電力、水、公共服務）的鎖定卡片即時更新；行政區、政策、公車、地鐵、電車工具也顯示對應 MS 鎖頭。慶祝視窗依序顯示名稱、人口門檻、已發放獎金及本級新內容，可以按按鈕或 Esc 關閉。視窗不改變模擬速度；關閉視窗不發獎。手機直／橫式可捲動且按鈕至少 44 px。

`unlocked` 是永久領獎記錄，存檔拒絕未知 ID、重複 ID 或缺少 MS0；`stats.milestone` 從有效記錄重建。舊版本已有高人口但未發獎的城市於恢復模擬的第一 tick 補領符合門檻的級別。已領城市讀檔不重播慶祝、不重領。關閉前保存也一樣，不需要額外領獎指令。

本卡解鎖資料也列出後續 M4-10 的土地與 M4-11 地標；相關建造操作由各卡完成，不在本卡假造建造入口。規則沿用 GDD 數值，未新增 runtime 依賴。
