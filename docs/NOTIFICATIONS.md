# M2-23 城市通知

右上方最多三張通知；火災優先，五秒實際時間後消失（暫停模擬也會消失）。每張都有 44 px 關閉按鈕。有世界位置的通知本身也是按鈕，點擊後清除建造／檢視選取，鏡頭平滑飛到該位置；財政屬全市資訊，沒有捏造位置。

`CityNotices` 在 UI 側維護 Worker 建築事件的唯讀投影，按增量維護缺電、缺水、火災與廢棄集合，不更改模擬狀態。問題持續時不重複發送；完全解除後才重新啟用。UI 同類再加 60 秒實際時間冷卻，防止快速反覆供電造成刷屏。財政沿用既有 economy warning/gameOver 狀態。

「廢棄過多」定義為至少 5 棟且達分區建築 20%，數值放 data/notifications.ts。讀取城市時提示現有問題；新城市重置集合與計時器。`milestone` 事件有一次性通知及位置支援，已解鎖里程碑在讀檔時不重播；自動里程碑解鎖／獎勵由既定後續里程碑任務負責，本卡不改遊戲解鎖規則。既有 `notify` 事件可透過 params.code 傳入六種受支援通知。

不增加 runtime 依賴。事件訂閱、ResizeObserver、通知計時器在卸載世界時完整釋放。
