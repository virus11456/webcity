# 大型火災與重建（M4-14）

暫停選單 → 設定的「啟用大型火災災害」預設關閉，隨每座城市存檔保存。開啟後以城市種子與遊戲日安排 14～35 天後的預警；預警提前 3 天，通知可定位，設定頁顯示預計發生日。讀取預警存檔不重新抽籤，並重新顯示定位通知。關閉會取消未發生預警，但不撲滅現有火災；重新啟用才重新排程。

災害最多點燃目標 120 m 內三棟完工建築，按距離與 ID 穩定排序；樹木排除。預警目標若已拆除或失去可起火狀態，此次取消，不轉移到其他區域。城市無可用目標則另排下一次。消防車沿真實道路救援，抵達才滅火，未撲滅每天損傷 50%，兩天燒毀，沿用 M2 消防系統。此選項管理大型區域災害；原本低機率日常建築火災保留。

點選燒毀建築可見「重建費用」及重建按鈕。公共建築按原始定價 50%，分區建築按占地格數 × $500 × 50%，向上取整；沙盒免費。Worker 檢查燒毀狀態、未待改分區拆除與資金，扣款一次後重啟 3 天施工動畫，完工才恢復容量。建築 ID、占地、遺體與設施庫存保留；當次實付成本取代拆除退款基準，避免舊成本重複退回。原有拆除工具仍可清理廢墟。

新增 disasters 狀態與 setDisasters／rebuild 指令，Worker 是唯一權威；主執行緒只讀鏡像與回應。舊存檔缺欄位補為關閉，非法日期或互斥狀態拒絕載入。沒有新增依賴，未加入地震、洪水或天氣對模擬的效果。
