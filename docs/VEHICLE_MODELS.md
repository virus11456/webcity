# M3-13 正式車輛

提供 16 款原創離線模型：6 款轎車（不同車頂長度、高度與尾翼）、3 款卡車（箱型、平台、槽罐），以及公車、警車、消防車、救護車、垃圾車、靈車、地鐵。可用 `?asset-gallery=1&model=veh_car_1` 檢視。地鐵僅提供美術素材，路線與運輸玩法仍屬 M4。

`npm run assets:models -- vehicles` 從 `src/render/vehicleModels/geometry.ts` 可重現產生 Meshopt GLB，兩段 LOD 與車體烤漆遮罩。模型使用 vertex color，無需額外貼圖（因此不建立空白 KTX2）；roughness 0.78、metalness 0。車輛以輪胎接地中心為原點，+Z 向前，沿用 Worker 的 4.4 m 轎車碰撞尺寸。模型不是外部素材，也不是 Blender 手工製作。

VehicleRenderer 以居民 ID 選擇穩定車型及 ART 指定的車色比例；烤漆遮罩保留輪胎、玻璃、燈具原色。每車型／LOD 一個 InstancedMesh，400 m 以外簡化、900 m 以外不顯示，行人仍於 120 m 以內顯示。GLB 載入時還原 Meshopt 量化轉換；下載失敗使用相同原創幾何，車輛不消失。移動、身分、工作地點與目的地完全沿用 Worker 資料。夜間頭尾燈仍使用兩個共用批次。

驗證涵蓋所有模型的雜湊、解碼、600/100 三角形預算、16 種不同外形、10,000 名居民的烤漆比例，以及實際城市載入與移動、16 款圖庫模型和手機直橫式／平板／桌機畫面。效能測試沿用真實通勤城市。

驗收紀錄：912 個全套單元測試通過；調整外形後再跑 10 個車輛單元測試。三種裝置的實際通勤／點選回歸皆通過，1,000 輛可見車輛、12 個 LOD 批次約 60 FPS，p95 16.7–16.8 ms。這是 Chrome 裝置視窗測試，非 iPhone Safari 實機量測。三裝置圖庫逐一解碼並顯示全部 16 款車輛，另檢查手機橫式。所有截圖在 `screenshots/m3-13/`。
