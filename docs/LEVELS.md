# M2-21 幸福度與建築升降級

Worker 按 GDD §12 逐棟計算 0～100 幸福度：基礎 50、缺電 −25、缺水 −25、未排污 −15、未收垃圾 −10；警消醫教覆蓋各 ×5、公園加成 ×0.5、地面污染 −0.3、噪音 −0.2、犯罪 −0.2、每個高於 9% 的稅率百分點 −1.5。個人取住家幸福度；城市按實際居民數加權，空城為 50。稅率、預算、放置、拆除等結構操作即時重算；財政日結依新環境再更新。搬入與 2% 整戶搬出使用各自住宅的幸福度，居民不會因另一區滿意而忽略自己住家的問題。HUD 顯示開心／普通／不開心與數值。

垃圾收運系統與政策工具尚在 M4；本卡在沒有垃圾覆蓋資料時視為區外收運，不施加垃圾罰分、不阻擋升級。未來 coverage.garbage 明確為 0 時立即扣分並阻止升級，正值恢復。已存入城市的政策按 data/policies 的 happinessDelta 加總；政策操作面板仍屬 M4。這是 M2 的相容約定，並不表示垃圾車已實作。

依 GDD §5.4 每十天檢查所有升級條件，每次只升一級：地價 21／41／61／81，住宅平均教育 0.5／1／1.5／2；商業、工業、辦公平均在職員工教育 0.6／1.2，最高 Lv3，住宅最高 Lv5。需要供電、供水及上述收運條件。荒廢、燒毀、施工、火災及待改分區不升級。每次升級重新核算容量、戶數及實際市民／職缺分配，舊住戶與工作指派盡量保留。平均員工教育取真實已填職缺，不以需求學歷代替。

地價低於目前門檻減 10，連續三十天後降一級；中途恢復即取消倒數，每次降級重新起算。development 保存最後結算、檢查與低地價開始日，暫停、同日重算及讀檔不加速。舊存檔以建造日或載入日初始化；期中進度保留並驗證數值。

檢視提供下一級、條件完成度／進度條、地價及教育門檻、水電與收運狀態。既有程序模型依 level 重新生成，共享材質與有上限的改建塵埃特效；模型替換與特效有渲染單元測試。

驗收包括完整 Lv1→Lv5 十日分段、商工上限、所有條件、三十日降級／恢復、期中存讀檔、容量與幸福度權重；真實管網、供電及六座大公園的住宅整合存檔可以升到 Lv5。瀏覽器以該存檔驗證真實 Worker 的四次升級，包含三裝置與手機橫式，截圖存於 screenshots/m2-21/。採 Chrome viewport 與觸控模擬，非 iOS Safari 實機。
