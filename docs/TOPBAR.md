# 城市頂部資訊列（M1-20）

頂部列顯示城市名、人口、今日淨移入、資金、上週淨收支、日期、速度、RCIO 需求與幸福度。這些數值來自模擬 Worker 的鏡像；展示街區中的裝飾建築不列入人口或財政。

## 資料與操作

- `createCityHudState()` 在 `ui/store.ts` 建立每座城市獨立的 signals；`topBarModel.ts` 訂閱 ready、stats、fundsChanged、economy 與 clock。每日統計更新需求、人口、幸福度及收支；建造／借款／還款的資金事件立即更新金額。
- 城市名用鏡像的唯讀字串 getter，讀統計用小型防禦性副本，不複製地形或每日歷史。clock 有自己的 signal，時鐘事件不重新複製 stats。
- 速度按鈕與既有鍵盤快捷鍵共用 `setSpeed`。只在收到 Worker clock 回報後更新選取；尚未 ready、連線失敗或破產終局皆停用。失敗訊息可見，並有 alert；時間狀態提供無障礙 status。
- 上週收支是 `income - expenses`，尚未完成第一週時為零；不是即時預估。每日淨移入是當天 movedIn 減 movedOut；數值的來源與重設沿用人口系統。
- 日期沿用 `dateForDay()` 與既有起始日，不受使用者所在時區影響。沒有在本卡改動模擬公式或新增幸福度系統；幸福度呈現 Worker 當前值。

## 四種版面

桌機在同一列顯示完整資料。平板分為統計與日期／速度兩列，控制至少 48px。手機直式與短橫式使用不換行的城市／人口／資金摘要，詳情按鈕開啟共用 BottomSheet；直式日期／速度獨立成第二列，橫式併排。字體至少 12px，控制至少 44px，頂部與兩側尊重 safe-area。

手機摘要的大數字採繁中 compact 表示，展開後顯示完整金額（含小數點兩位）與人口。城市長名稱省略顯示，完整名稱保留於 title 與詳情標題。負資金與負週收支標紅，同時保留負號。

RCIO 使用分區色板，帶字母、數值與有名稱的 meter，範圍沿用 0–100。詳情開啟時仍會接收每日更新，Esc／關閉後回到詳情按鈕；轉成非手機版面時關閉詳情。

資訊列 ResizeObserver 在尺寸變動時更新共用底部位置，讓既有建造摘要與除錯文字避開頂部列；卸載時解除所有訂閱、尺寸觀察及 DOM。原型工具列與財政按鈕保留，正式工具列、預算面板、選單及資訊圖層按各自任務接續。

## 驗證約定

單元測試使用真實 SimClient／WorldMirror 加受控傳輸，涵蓋負資金即時同步、每日 RCIO／人口／幸福度、城市名、speed 等待確認、失敗與破產禁用、dispose 及 clock 不複製 stats。E2E 比對實際 Worker 每日統計與借款後資金；另用明確標記的 Worker 訊息 fixture 驗證負大金額及長城市名的顯示，不把 fixture 當作財政模擬證據。

截圖保存在 `screenshots/m1-20/`，包括三裝置、手機詳情與橫式。觸控為 Playwright Chromium 模擬，非 Safari／iPhone 實機測試。

驗證結果（2026-10-10）：lint、typecheck、build 及 686 項單元測試通過；完整回歸先有 88 通過／11 略過，3 項同源截圖流程誤用探索模式按鈕，修正後 6 項資訊列 E2E 全數通過。合計涵蓋 91 個不重複通過案例，包含既有三裝置速度、快捷鍵與離線重載。
