# 主工具列（M1-21）

建造分類放在底部；手機橫式移至左側，選項在右側窄面板。物件卡片使用原創線條圖示，直接讀取 `ROADS`、`BUILDINGS`、`NETWORKS`、`ZONES` 的價格、每週維護及里程碑，不另存平衡數值。道路／管線的價格明確以每 8m 表示，分區免費。

卡片與下拉選單共用既有工具指令，Worker 仍重新驗證每次建造。未解鎖卡片禁用並顯示鎖頭及 MS 等級；等待 Worker 回覆時禁用切換。道路目前只有直線，分區保留填滿、矩形、小／大筆刷與清除；旋轉只在設施放置時出現。確認、取消、旋轉以黏附面板底部的浮動操作區呈現。

保留 GDD 既有 `1`／`2`／`3` 速度鍵，新增 `4` 道路、`5` 分區、`6` 電力、`7` 水務、`8` 拆除。僅畫布或工具列焦點有效，輸入欄位、選單、對話框與瀏覽器修飾鍵不攔截。畫布 Esc 取消草稿；工具列 Esc 返回探索。雙指仍交給相機。

公共服務等未實作分類集中於「後續開放的分類」說明，避免出現可按卻無功能的分類。M2 交通／市民通勤及 M4 服務尚未在此卡實作。

版面限制面板高度、保留中央地圖操作區。橫向卡片與分類可觸控捲動，頁面本身不捲動；桌機／手機至少 44px，平板按鈕 48px。生命週期清理鍵盤與共享 layout 訂閱。

驗證包含實際卡片→工具狀態、費用／鎖定、分區清除、設施旋轉、速度及分類快捷鍵、手機旋轉與四版面截圖。既有道路、水電、分區、人口、財政等流程以完整 E2E 回歸。觸控為 Playwright Chromium 模擬，尚未進行 iOS 實機驗證。
