# M1-15 電力系統

建造模式新增「電力」工具，可放置開局的風力機及燃煤電廠，或架設電線。滑鼠與觸控皆先點地面預覽，再按「確認設置」；電廠可轉 90°，預覽顯示占地、16m 接電範圍、價格與實際預估 MW。電線點兩個端點後確認；綠色範圍包含線路與端點，方便判斷能否接到住宅。取消、雙指手勢與切換工具都不扣款。

## 權威與建造

`place` 及 `buildNetwork(net:'power')` 現在由 Worker 驗證並原子提交。純函式 `previewPlant`／`previewLine` 同時用於主執行緒預覽與 Worker 再驗證；預覽不是保留價格或施工授權。拒絕非法座標、未知設施、未解鎖、未購土地、缺錢、地形不合與建築／道路重疊。

電廠原點與其他建築一樣是正面中心、深度沿旋轉後 +Z；所有角度先正規化。整個足跡須位於可用土地，坡度 ≤0.15 且四角高差 ≤4m，避免服務建築浮在山坡上。風力機 $2,000，占地 2×2；煤廠 $19,000，占地 6×6。服務設施在確認後即投入運轉，住宅三日施工不變。

電線可跨水，電纜與預覽保持在水面以上，單次最多 32 點、總長 960m，每段至少 8m，價格為 `ceil(總長/8) × $10`。不限制必須沿道路，亦不消耗道路或分區格。用土地邊界切分線段後驗證每段，不會漏掉小於取樣間隔的未購地角落。可穿越建築上方；此階段尚無塔柱／屋頂 3D 碰撞。沙盒依現有規則免費。

電廠與電線記錄 builtDay／paidCost，沿用現有拆除工具及七日內退款規則。電廠足跡加入分區及道路碰撞。每次供電更新只傳 flags 部分更新及 transient stats；不用完整世界快照更新 UI。網路 ID 同步進鏡像 nextId。

## 供電圖與容量

只將 active 建築與電線放入圖。矩形建築以足跡邊緣、電線以線段計算最近距離，≤16m 建立連線；電線交叉可接通。先用 64m 空間桶篩選候選，再做精確距離與 BFS，分出各自獨立的供電群組。施工中、荒廢及燒毀建築不傳電。

每群供電量由群內發電設施相加；別的獨立群組即使有剩餘電力也不能補給。按照建築到群內最近有效發電源的直線距離排列，同距離按 ID。容量不足時從最遠的負載逐一斷電，保留完整的近端前綴，不讓小型遠端建築插隊。負載未獲供電仍保留實體導體連線，避免容量分配改動拓樸。

用電遵循 GDD：實際入住戶數 ×0.006MW、商業總職位 ×0.008、工業 ×0.012、辦公 ×0.010。未定義的服務負載尚不加入。flags 位元 1 表示 HAS_POWER，其他位元保留。`stats.power` 為 produced（所有電源輸出）、consumed（所有用電需求）、served（實際供應）、unpowered（有需求但缺電的建築數）、groups（獨立導電群組數）。所以全市發電大於需求仍可能有隔離區塊缺電。

建造、拆除、道路變更、住宅完工與人口變化時重新計算；每日人口結算後亦更新。暫停中放電廠／接線／拆除也立即生效。缺電造成幸福度、警示圖示與荒廢的計時器屬 M1-17 及後續任務，這張卡不偷偷啟動那些懲罰。

## 風力場與模型

原地圖尚沒有風力資料，因此新增按 seed 固定的連續程序風力場：320m 格點雜湊值經平滑雙線性內插成 0～1，風力機輸出為取樣 ×4MW。預覽、Worker 和模型使用同一 seed／位置，不使用 Math.random 或時鐘；旋轉不改風力產量。目前風力不隨天氣改變，沒有另建風力熱圖圖層。

風力機、三葉轉子、煤廠、煙囪與架空電塔均為原創低多邊形幾何，配色來自既有色板。風車速度隨局部風力改變；這是裝飾動畫，模擬暫停時不改變電量。資產由 acknowledged events 建立／刪除，預覽不會混入城市資料。替換或刪除 mesh 時釋放 geometry，材質由 renderer 統一管理，更新轉子不在每幀配置物件。

本卡完成開局電網與兩種開局發電設施。燃油、太陽能及跨河水壩的進階設施放置／模型尚未開放；水壩尺寸與水頭公式本來未定義，不能假裝實作。維護費結算、污染／噪音場依相應後續任務接入。沒有新增 runtime 依賴。

## 驗證

單元測試涵蓋鄰棟接電、16m 邊界、交叉電線、跨區接線與拆線、獨立電網、合併電源、遠端優先斷電、active 篩選、各分區用電、拆電廠、風力種子與連續性、旋轉足跡、地形／道路／建築／土地／資金檢查、未購地微小角落、價格與退款、唯一 ID、鏡像一致、未授權輸入、預覽確認／取消／防重送與資源釋放。

Playwright 原生滑鼠與觸控模擬：建住宅 → 缺電 → 放旋轉風力機 → 確認有產電但孤立 → 接線供電 → 拆線缺電 → 拆電廠產量歸零，並截圖預覽、接通與斷線。iPhone 另檢查橫式控制項與無頁面溢出；裝置模擬不是 Safari 實機測試。
