# M3-16 UI 美術

全部原創 24×24、2px 圓端線條圖示集中在 `data/icons.ts`。工具、六種分區、所有 BUILDINGS／NETWORKS／ROADS、19 種資訊圖層與全部問題均有對應。Preact 和既有 DOM 控制使用同一組路徑，城市屋頂問題圖集也直接繪製相同 SVG Path2D。按鈕保留可讀文字及原本可及性名稱，不用字元或 emoji 代替圖示。

既有 imperative 控制透過 `decorateControls` 補圖示，只在 DOM 內容變動時檢查新增控制或受影響按鈕，不在每幀掃描整個 UI。已有 SVG 的按鈕不重複插入。資訊圖層增加可按的圖示清單，保留原本 select 與事件路徑。

物件卡片以遊戲同一個 WebGLRenderer 在 256×160 離屏目標產生透明 PNG。分區使用正式 catalog 的原創來源幾何（不支援規格沿用程序來源），公共設施使用同款來源幾何，與正式 GLB 的離線建模來源相同。縮圖是模型的靜態預覽，不播放施工動畫。渲染後完整還原 target、viewport、scissor、clear 與 autoClear，移除並釋放臨時幾何；最多快取 64 張，無第二個 WebGL context。UI 只接受 game 注入的字串 callback，不操作 Three 或世界狀態。

面板使用 180ms 淡入與上滑；`prefers-reduced-motion` 關閉動畫。手機工具列使用圖示上、文字下，延續 44px 觸控目標與安全區；資訊層清單可獨立捲動。物件卡片使用已確認的建築資料與問題圖示。

驗證包含完整圖示清單對照、三裝置實際選取建築與離屏縮圖、服務圖示、資訊圖層按鈕、可見按鈕 SVG 覆蓋、手機橫式與頁面無水平溢出。截圖在 `screenshots/m3-16/`。裝置測試為 Chrome 模擬，未宣稱實機 Safari 驗證。

驗證結果：lint、typecheck、build 通過；完整單元測試 922 項通過。21 項跨裝置 UI、工具列、主選單、資訊層、通知與物件選取測試分批通過；新增面板較高，空白場景關閉測試改點可見空地，仍保留 CANVAS 命中與解除選取斷言。手機、平板、桌機與手機橫式截圖已目視檢查。
