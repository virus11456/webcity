# WebCity 企劃書（Cities: Skylines 風格城市模擬・Web / PWA）

> 版本：v0.1（企劃階段）　日期：2026-10-05
> 目標：在瀏覽器上做出玩法與美術風格接近《Cities: Skylines》的城市建造模擬遊戲，支援 PWA 安裝，可在 iPhone、iPad、PC 上遊玩。

---

## 0. 重要前提（版權）

- 「跟 Cities: Skylines 一樣」指的是**玩法類型與美術調性**一致，不能直接使用 Paradox / Colossal Order 的素材、模型、貼圖、音效、UI 圖示、Logo 或遊戲名稱。
- 所有 3D 模型、貼圖、圖示、音樂音效都要**原創、程序生成，或使用 CC0 / 可商用授權素材**（例如 Kenney、Quaternius、Poly Haven）。
- 遊戲名稱暫定 **WebCity**（之後可再改）。

---

## 1. 遊戲概念

| 項目 | 內容 |
|---|---|
| 類型 | 3D 城市建造 / 經營模擬（單人、離線可玩） |
| 核心循環 | 鋪道路 → 劃分區域（住宅/商業/工業/辦公）→ 提供水電與公共服務 → 人口成長、稅收增加 → 解鎖新建築 / 擴張土地 → 解決交通、污染、財政問題 |
| 遊戲時間 | 一場數小時以上，可隨時存檔、離線續玩 |
| 平台 | 瀏覽器（Chrome / Safari / Edge / Firefox），PWA 安裝到主畫面 |
| 裝置 | PC（滑鼠+鍵盤）、iPad（觸控 / Apple Pencil / 鍵盤）、iPhone（觸控，直式與橫式） |
| 語言 | 繁體中文為主，預留 i18n（英文） |

### 1.1 對標 Cities: Skylines 的核心特色

1. **自由曲線道路**：直線、曲線、自由手繪道路，各種道路等級（2 線道、4 線道、單行道、大道、高速公路、交流道）。
2. **沿路自動產生的分區格**：道路兩側自動產生 4 格深的可分區格子（每格 8m×8m）。
3. **RCI(O) 需求系統**：住宅 / 商業 / 工業 / 辦公需求條。
4. **建築自動成長與升級**：建築依地價、服務覆蓋率升級（1～5 級）。
5. **每個市民都是模擬個體（Agent）**：通勤、購物、上學，造成真實交通流量。
6. **水電網路**：發電廠＋電線、抽水站＋水管＋污水排放。
7. **公共服務覆蓋範圍**：警察、消防、醫療、教育、垃圾、殯葬、公園。
8. **區域政策（Districts & Policies）**：繪製行政區並套用政策。
9. **大眾運輸**：公車、地鐵、電車路線。
10. **里程碑解鎖**：依人口解鎖新功能與新地塊。
11. **資訊圖層（Info Views）**：交通、地價、污染、噪音、水電、覆蓋率等。
12. **日夜循環、天氣、地形編輯**。

## 2. 美術風格（Art Direction）

目標：還原 Cities: Skylines 的「**寫實偏可愛的微縮城市**」觀感。

### 2.1 風格關鍵字
- **低～中多邊形寫實風**（不是像素、不是卡通 Q 版），比例正確、細節靠貼圖與色彩表現。
- **明亮自然光**：偏暖的太陽光 + 藍天環境光，柔和陰影。
- **移軸（Tilt-shift）微縮感**：拉近鏡頭時有景深模糊，讓城市看起來像模型。
- **飽和但不刺眼的色彩**：綠色草地、深藍水面、灰色柏油路、紅/米/白色系建築。
- **分區色彩識別**（遊戲 UI 常見慣例，用自己的色碼）：
  - 住宅：綠 `#5DBB46`
  - 商業：藍 `#3C8DDE`
  - 工業：黃 `#E8B931`
  - 辦公：青 `#3FC1C9`
- **UI 風格**：深色半透明面板、圓角、白色線性圖示、底部主工具列、頂部資訊列（人口 / 金錢 / 時間 / 速度）。

### 2.2 視覺元素清單
| 元素 | 做法 |
|---|---|
| 地形 | Heightmap 網格 + 多層貼圖混合（草地、泥土、岩石、沙灘），依坡度與高度自動上色 |
| 水 | 半透明水面 Shader：法線貼圖波紋、菲涅耳反射、岸邊泡沫、水深顏色漸層 |
| 天空 | 漸層天空盒 + 太陽，日夜循環（晨昏橘紅、夜晚深藍） |
| 道路 | 依曲線動態產生的網格 Mesh，柏油貼圖 + 白/黃標線 + 人行道邊緣 |
| 建築 | 每種分區 × 等級 × 3～6 款模型；低模 + 色彩貼圖（窗戶、屋頂），夜晚窗戶自發光 |
| 樹木 | Billboard / 低模樹 Instancing，大量種植 |
| 車輛 / 行人 | 低模車輛 Instancing，數十種配色；遠景行人可省略或以點表示 |
| 特效 | 工廠煙霧、火災、施工中鷹架、建築升級光圈 |
| 後製 | 色調映射（ACES）、SSAO（PC）、景深移軸、Bloom（夜晚燈光）、FXAA |

### 2.3 素材策略（三階段）
1. **MVP**：程序生成方塊建築（不同高度、屋頂、顏色、窗戶貼圖由 Canvas 生成）→ 不需美術也能看起來像城市。
2. **Alpha**：引入 CC0 低模素材包（Kenney City Kit、Quaternius）並統一調色。
3. **Beta**：自製 / 委外製作專屬建築模型（Blender → glTF + Draco/Meshopt 壓縮 + KTX2 貼圖）。

### 2.4 畫質分級（依裝置自動選擇，可手動調整）
| 等級 | 對象 | 陰影 | 後製 | 渲染解析度 | 車輛上限 |
|---|---|---|---|---|---|
| 低 | 舊 iPhone | 無 / 簡易 | 無 | 0.75x | 300 |
| 中 | iPhone 新機 / iPad | 1 張 1024 陰影圖 | FXAA + 移軸 | 1x | 1,000 |
| 高 | PC / iPad Pro | 2048 CSM 陰影 | SSAO + Bloom + 移軸 | DPR | 3,000+ |

## 3. 技術架構

| 層 | 技術選擇 | 理由 |
|---|---|---|
| 語言 | TypeScript | 大型專案型別安全 |
| 建置 | Vite | 快速、內建 PWA 外掛生態 |
| 3D 引擎 | Three.js（WebGL2，未來可切 WebGPU） | iOS Safari 支援度最好、生態成熟 |
| UI | 原生 DOM + CSS（或 Preact，輕量） | HUD 不需要重框架，保持效能 |
| 模擬 | **Web Worker** 執行模擬（交通、經濟、成長），主執行緒只負責渲染 | 避免卡頓，手機也順 |
| 資料結構 | TypedArray（Float32Array / Uint16Array）存格子與 Agent 資料 | 記憶體與效能 |
| 存檔 | IndexedDB（壓縮後的二進位存檔）+ 匯出/匯入檔案 | 可存大型城市、離線可用 |
| PWA | vite-plugin-pwa（Workbox）、Web App Manifest、離線快取 | 安裝到主畫面、離線遊玩 |
| 測試 | Vitest（模擬邏輯單元測試）+ Playwright（UI / 手機尺寸 E2E） | |
| 部署 | GitHub Pages 或 Vercel（HTTPS 必要） | |

### 3.1 世界規格
- 格子單位：**8m × 8m**（同 CS）。
- 起始地塊：2km × 2km（256 × 256 格）；可解鎖擴張至 3×3 地塊（6km × 6km）。手機版預設上限可較小。
- 道路網路：**節點（Node）+ 路段（Segment，三次貝茲曲線）** 的圖結構，分區格子依路段生成。
- 模擬 Tick：遊戲 1 天 ≈ 實際數秒（可調速 ×1 / ×2 / ×4，暫停）。

### 3.2 程式模組
```
src/
  main.ts                 進入點、偵測裝置與畫質
  core/                   事件匯流排、時間、亂數、設定
  world/                  地形、格子、道路圖、分區、建築資料
  sim/ (Web Worker)       需求、成長、經濟、水電、服務、污染、地價、市民 Agent、交通尋路
  render/                 場景、地形、水、道路 Mesh、建築 Instancing、車輛、日夜、後製、資訊圖層
  input/                  滑鼠/鍵盤/觸控手勢、相機控制、工具系統
  ui/                     HUD、工具列、面板、通知、設定、教學
  save/                   序列化、IndexedDB、匯入匯出
  pwa/                    Service Worker 註冊、更新提示、安裝提示
public/                   manifest、圖示、splash
```

### UI 版面

## 5. 遊戲系統設計摘要

### 5.1 道路
- 種類：小路（2 線）、中型道路（4 線）、大道（6 線，中央分隔島）、單行道、高速公路、交流道、橋樑、隧道（後期）。
- 鋪設模式：直線、曲線、自由曲線、升級（替換道路等級）。
- 自動處理：路口生成、交叉切割、對齊格線 / 角度吸附（15°）、坡度限制。
- 路口可設紅綠燈 / 停止標誌。

### 5.2 分區與建築成長
- 分區：低密度住宅、高密度住宅、低密度商業、高密度商業、工業、辦公。
- 建築生成條件：已分區 + 臨路 + 有需求 + 有水電。
- 等級 1～5：依地價、教育程度、服務覆蓋率升級。
- 廢棄條件：長期無水電、無工作者、高犯罪、無顧客等。

### 5.3 需求（RCI）
- 住宅需求 ← 工作機會、幸福度、稅率
- 商業需求 ← 人口購買力、貨物供應
- 工業需求 ← 勞動力、商業貨物需求、出口
- 辦公需求 ← 高教育人口

### 5.4 市民與交通（核心難點）
- 每個市民有住處、工作、學校、年齡、教育程度、幸福度。
- 每日行程：家 → 工作/學校 → 購物 → 回家。
- 尋路：道路圖上 A* / 分層路網（Contraction Hierarchies，後期優化），結果快取。
- 車輛沿車道移動、路口排隊、壅塞計算；交通流量回饋影響商業與貨運。
- 效能：手機版上限市民 Agent 數量並以「代表性 Agent（1 輛車代表 N 人）」縮放。

### 5.5 水電與基礎設施
- 電力：燃煤 / 風力 / 太陽能 / 水力發電；電線連接；建築相鄰時自動傳導電力。
- 水：抽水站（需水源）、水管（沿道路自動鋪設選項）、污水排放口（造成下游水污染）。
- 垃圾：掩埋場、焚化廠；垃圾車需能抵達。

### 5.6 公共服務
警察局、消防局、診所 / 醫院、小學 / 高中 / 大學、公園與廣場、墓園 / 火葬場；每種有覆蓋範圍、容量、維護費，並透過道路派車。

### 5.7 經濟
- 收入：各分區稅收（可個別調整稅率）。
- 支出：建造費、每週維護費、各部門預算滑桿（影響服務效能）。
- 貸款：最多 3 筆。
- 財務面板：收支圖表。

### 5.8 環境
地價、空氣/地面污染、噪音、水污染；以格子場（Field）模擬並擴散。

### 5.9 進度
- 里程碑：依人口（500、1,000、2,500…）解鎖道路、服務、政策、地塊擴張。
- 成就（選配）。

### 5.10 行政區與政策
畫筆繪製行政區、命名；套用政策（禁止高樓、免費公車、回收計畫、工業特化：林業/農業/礦業/石油）。

### 5.11 大眾運輸
公車站/路線編輯器、地鐵（地下層）、電車；乘客量與票價收入。

### 5.12 其他
日夜循環、天氣（雨、霧）、災害（火災為主，後期加其他）、地形編輯（整地、挖河）、拍照模式、自由視角跟隨車輛/市民。

## 9. 風險與對策

| 風險 | 影響 | 對策 |
|---|---|---|
| iOS Safari 記憶體上限（約 1～1.5GB 會被強制重新載入） | 大城市當機 | 手機版限制地圖大小與 Agent 數、貼圖壓縮、記憶體監控自動降畫質 |
| 交通 Agent 模擬計算量大 | 卡頓 | Worker、代表性 Agent、路徑快取、分幀計算 |
| 曲線道路與路口幾何複雜 | 開發延誤 | M1 先做直線但資料模型採曲線圖結構，M2 再上曲線 |
| 美術素材量龐大 | 品質不一 | 先程序生成 → CC0 素材 → 自製，統一調色板與比例規範 |
| 手機觸控誤操作 | 體驗差 | 工具模式明確切換、確認/取消按鈕、Undo |
| 版權問題 | 法律風險 | 只參考玩法與調性，素材全部原創或 CC0 |
