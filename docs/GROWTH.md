# M1-12 分區長出建築

進入「開始鋪路」，沿路塗住宅、商業或工業分區，再播放時間。前排有空位且占地合法就會開工；「查看建築」移近正在施工的房屋，並在既有四棟施工／十六棟近景預算內優先顯示該棟細節。施工從地基、結構、收尾到完工連續呈現。面板顯示施工／完工／待拆重建數量。

## 權威與地塊

- Worker 每 tick 對 R、C、I、O 各取 `floor(demand / 20)` 次嘗試，上限 5。RL／RH、CL／CH 分別共用預算，依可用格數加權。一般模式初始需求是 70／20／20／0；M1-14 已接入每日動態需求，見 [需求系統](DEMAND.md)。
- 從前排合法空格挑選種子，枚舉包含它的合法寬深矩形，隨機選一個。整塊同分區、已購土地、已解鎖、道路可分區、沒有占用，才檢查整個矩形的地形三角形：必須高於水面且坡度嚴格小於 15%。空間索引再排除跨區塊建築重疊。
- 候選、地形與建築空間索引快取；道路、分區、土地、解鎖、地形或拆除改變時重建。新增建築增量加入索引；隨機流由世界 seed 與絕對 tick 決定，不使用牆鐘或畫格時間。
- 前排位置沿用 ZoneBlock。世界深度為旋轉後 +local Z，模型 -Z 額外轉 π；道路兩側、斜路及碰撞占地一致。彎路的單格切線區塊只會生成寬度允許的建築，不跨有角度的區塊拼矩形。
- `buildingAt`、全域 nextId、施工 Building 都只由 Worker 寫入；鏡像採防禦性複本。道路切段會重連存活建築的 zoneBlock／blockCell。

## 三天施工與改分區

開工記錄 `constructionStartedTick`；30 tick 後才變 active。每 tick 的 stateTimer 以遊戲天表示，渲染只對已知進度插值。暫停停止 tick，倍速僅加快同一條時間線。

已有建築的格子可改分區或清除。任一占用格不符原種類時，記錄三天後的 `rezoneAtTick`；再改色不延長期限，所有格子恢復原色則取消。期限到釋放占地、移除建築，不退款；空地可依新分區再成長。單純刪掉道路仍採 M1-09 的斷路荒廢規則，不會當作改分區拆除。

占用變動事件附 `occupancyOnly`，不改格碼與拓撲。施工時間更新不觸發工具完整重建，塗抹中的筆畫能持續。新增建築只更新道路碰撞資料，不重建道路與地形網格。

## 驗證與目前範圍

單元測試涵蓋六區尺寸、正面臨路、兩側旋轉與模型深度、重疊、坡度／水面、解鎖與用地、共用需求預算、固定 seed 重播、精確施工期限、改色取消／倒數／拆除／再生、Worker／鏡像 ID、道路切段及筆畫不中斷。

Playwright 以原生滑鼠與觸控在 iPhone 15、iPad Pro 11、桌機實際鋪路、填住宅／商業、播放、暫停、查看建築、完工、清除已占用分區並等候拆除。另驗證手機橫式與高畫質材質沒有瀏覽器錯誤。截圖在 `screenshots/m1-12/`。

這張卡是建築成長。容量、人口入住、就業屬 M1-13；每日需求屬 M1-14；水電及服務警示、居民行程與動態車輛各依後續任務。此版仍沒有城市存檔，重整會清除試建內容。
