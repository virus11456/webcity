# M1-16 水與污水系統

建造模式新增「水務」：水塔、抽水站、污水排放口、已達里程碑 4 的污水處理廠，以及地下水管。先選位置／管線端點，按「確認設置」才由 Worker 扣款。使用水管或「沿道路自動鋪水管」預覽時，地面變半透明，地下藍色管線與 48m 覆蓋範圍顯示；離開工具恢復地面。雙指照常控制相機並取消草稿。

## 玩法與建造

- 每個水務設施需要 HAS_POWER 才有產能；斷電立即停供／停止排污，恢復通電立即重算。設施尚無額外服務用電量，沿用 M1-15 的零負載服務建築約定。
- 水塔 $3,000、6,000m³/週；抽水站 $2,500、12,000；排放口 $2,500、30,000；處理廠 $25,000、30,000，需里程碑 4（目前正常模式未有里程碑進度工具，沙盒可放）。設施確認即運轉，住宅三日施工不變。
- 原 GDD 未訂尺寸：本卡約定水塔／抽水站／排放口 2×2 格、處理廠 4×4 格。沿用正面中心原點及旋轉後 +Z 深度；旋轉按 90°，渲染、預覽、碰撞和 Worker 使用同一足跡。
- 水塔與處理廠沿用陸地最大坡度 0.15／四角高差 4m；岸邊設施放寬至 1.5／16m，主體足跡仍須完全乾燥，模型以水平平台和支柱跨越岸坡。
- 抽水／排放管從正面向外延伸 32m，端點必須位於已購土地且地形至少低於水面 1m，否則顯示岸邊原因。未做 3D 外伸管碰撞；沒有自動整平地形。
- 水管 $10 / 8m，按每段實際總長向上取整。手動一筆 8～4,800m、最多 4,096 點，節點間最短 0.1m；UI 為兩端點，接近既有管線 8m 內會吸附。地下管可以穿過水面與建築，土地檢查沿每個地塊邊界切分，避免漏過窄小未購地區。
- 自動鋪管先預覽所有道路缺少的中心線部分及總價，確認後一次驗證與提交。沿既有曲線取樣；已被水管覆蓋的部分不重複計費。道路後續移動／拆除不自動移動／拆水管，原管仍可使用或單獨拆除；重複按自動鋪管不花錢。小於 8m 的剩餘自動片段仍補齊，按至少一個 8m 單位計費。
- builtDay、paidCost、唯一 ID、七日內實付退款、沙盒免費與鏡像一致沿用既有機制。任一自動鋪管片段無效或總款不足時全部不建、不扣款、不消耗 ID。

## 水網與容量

實體水管相交或相距 ≤2m 才連通，64m 空間桶篩選後精確檢查，再以 BFS 分組。48m 是建築服務範圍，不是水管互相連接距離。住宅不能轉接水網。

每棟 active 建築按足跡到水管的最短距離接到 48m 內最近一條管；同距離依管 ID。設施也依此接網，不能透過一棟設施橋接兩個未連通的水管區塊。不同群組不共用容量。這個明確規則避免排序與重複覆蓋造成不確定分配；玩家需實際把管線相接。

用水量為實際入住戶數 ×12m³/週，商／工／辦總職位 ×10；未定義的服務用水暫為零。供水及排污各自依群內有效來源距離由近到遠分配，容量不足時保留完整近端前綴，不讓更遠的小負載插隊。未施工完、荒廢或燒毀建築不納入服務。

水與污水旗標各為 bit 2／4，保留電力及其他旗標。計算順序為電力 → 水務；每日、住宅完工／人口變更、設施放置／拆除及管線變更皆更新。暫停中也立即回覆。

`stats.water`：produced 是全市通電設施產能，consumed 是全市需求，served 是實際獲供，unserved 是缺水的需求建築數，groups 是水管群組數。`stats.sewage`：capacity 是通電排污產能，produced 是與用水需求相等的預估污水量，treated 是實際可接收量，uncollected 是未接收的建築數。因此這裡的「排放」是服務量／容量核算，沒有水力壓力、儲水或逐戶流量時間延遲。污水需求採潛在用水量，即使缺水仍保留排污需求，方便獨立呈現問題。

## 顯示與架構

`world/waterUtility.ts` 共用純放置／鋪管驗證；只將 M1-15 的場址與管線驗證參數化，保留原電力介面及測試。`WaterTool` 經 `place`／`buildNetwork(net:'water')`／新 `buildRoadPipes` 發送請求，最後一種由 Worker 重新計算所有片段及總價，不信任 UI 價格。鏡像以 `readPowerWorld('water')` 取得小型工具資料；名字保留以減少無關重構。

`WaterUtilityRenderer` 提供原創水塔、泵房、出口及處理槽；實際管線／覆蓋各合併為一份幾何，每次網路事件才重建，沒有每幀配置。地下管以地形下 4m 的 X-ray ribbon 顯示並關閉深度測試，讓道路／建築不遮擋線路；地形透明度 0.35，仍可正常地形選取。切換工具只調整視覺，沒有改變世界資料；移除及重建會釋放幾何，材質統一管理。沒有新增套件或外部素材。

## 範圍與後續

本卡完成水務容量、連接、通電依賴、放置及視覺。水污染場、河流污染輸送、飲用污染水與健康／幸福度後果由 M2-20 環境場與醫療服務等後續任務接入，未假裝已有這些效果；缺水／污水問題圖示與棄置計時為 M1-17，維護費為 M1-18。GDD 原句「抽水站下游若有排放口，取到污染水」與河流方向相矛盾；本卡遵循教學 §18「排放口在抽水站下游」，污染計算尚未啟用，之後應以此流向驗證。

## 驗證

單元測試涵蓋 48m 邊界、管線相交／斷線／孤島、來源斷電、供水及污水容量不足、兩種來源合併、分區負載、施工／荒廢／燃毀排除、旗標保留、順序不變性、原始地圖岸線、旋轉／鎖定／地形／碰撞／預算、地下跨水、吸附、沿路缺口、重複鋪管、鏡像／扣款／退款、Worker 輸入、工具取消／確認防重送及 GPU 幾何釋放。

Playwright 使用原生滑鼠及 Chrome 觸控模擬：住宅成長 → 水塔未通電 → 放風車恢復產能 → 沿路自動鋪管 → 重複無費用 → 手動連接供水 → 拒絕內陸抽水站 → 在真實河岸旋轉放置排放口 → 先通電但未連管 → 接管排污 → 拆供水管缺水 → 拆排放口停止排污。iPhone 包含橫式、44px 控制項及頁面無溢出。模擬不等於 Safari 實機驗證。
