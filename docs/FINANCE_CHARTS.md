# 財政趨勢（M4-15）

財政面板的「52 週財政趨勢」可切換收入、支出、資金餘額，選擇週次查看當週三項精確金額。鍵盤 Home／End／方向鍵及觸控滑桿皆可操作。

資料來自既有 statsHistory 中每 7 天結算完成時的快照，顯示最近 52 個已完成週內的結算紀錄。收入是稅收與交通票價等當週總收入，支出為維護、政策與還款；建設扣款、拆除退款、貸款與里程碑獎金反映在資金餘額，不能用折線收入減支出直接推回所有資金變化。每日重複顯示的上週收入不再加總。未完成週不顯示；缺週保留時間空隙且斷線，無資料則提示目前沒有最近 52 週的已完成結算紀錄。

Canvas 2D 原生繪圖，不加套件；產生位圖供 img 顯示，頁面的互動 canvas 保留給遊戲。各指標有自己的含零縱軸，負餘額有零線；週次滑桿提供選取標記與文字數值，顏色非唯一資訊來源。資料未變不重畫，只在面板展開、變更選取或尺寸時繪製；資源在離開城市時清理。

WorldMirror 只複製小型 FinancePoint 陣列，不複製地形或改變 Worker 狀態。沿用原始城市存檔，無新增儲存格式；舊城已有結算歷史會直接顯示。

單元測試涵蓋 52 週截取、結算邊界、負值、零值、缺週、重複／非法樣本、實際 Worker 結算、鏡像防修改及保存還原。三裝置 E2E 驗證圖像、指標切換、數值、鍵盤與手機橫式觸控、重載紀錄。
