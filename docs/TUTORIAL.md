# M5-01 新手教學

新遊戲預設勾選教學，可在主選單取消。勾選時城市以暫停開始；舊存檔缺少教學欄位時視為已跳過，不打擾既有城市。可收合提示卡或隨時跳過；跳過不發獎勵，亦不改變時間速度。

## 步驟與判定

1. 真實輸入完成平移、旋轉、縮放；桌機顯示 WASD／Q E／滾輪，觸控顯示雙指手勢示意。自動鏡頭飛行不算操作。
2. 有一段可分區道路實際接到高速公路匝道。
3. 同一匝道連通路網有至少三段可分區道路；斷開的道路不計。
4. 世界目前有住宅、商業與工業用地，並說明 RCI 需求條。
5. 啟用的風機透過相連電線到達住宅用地（沿用 16m 供電距離），空地尚未長房也可完成。
6. 啟用的抽水站與污水排放口連到同一水管網，並覆蓋住宅用地。設施選擇最近管線，管線接合 2m、設施／用地覆蓋 48m，沿用遊戲數值。提醒排放口放下游、設施需要電力；本步檢查建設連接，不宣稱水質或供電量已經足夠。
7. 啟動時間且至少一棟分區建築已完工；可看既有四階段施工動畫。
8. 使用者打開財政面板後完成，Worker 一次發放 $5,000。

建造步驟依序檢查，提前完成的現存建設可接續通過。已完成步驟不因後續拆除／復原退回；這是操作教學，持續供需由正常模擬與警示處理。教學不限制自由建造、不強制自動開關工具、不變更經濟規則。沒有重新領獎／重置按鈕。

## 儲存與 UI

`WorldSnapshot.tutorial` 保存 status、step、camera 位元組及完成訊息 dismissed。主執行緒只上報實際鏡頭操作、財政開啟或跳過，不能提供步驟或獎勵金額。Worker 建造成功／成長 tick 以世界狀態推進；存檔驗證拒絕非法步驟與旗標。讀檔、重複財政事件、跳過及建造復原都不能再次領取已發放的獎勵。

提示卡位於 HUD 下方，按鈕至少 44px；可收合，橫式在右側避開工具。操作定位按鈕捲動工具列到當前功能並開啟對應工具，輪廓與箭頭標示位置；箭頭不攔截場景輸入。開啟對話框時讓出畫面。
