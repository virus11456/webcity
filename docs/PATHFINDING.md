# M2-09 尋路

Worker `Pathfinder` 以 M2-06 車道圖產生數值化 A* 圖。最小二元堆積、距離／父節點／探索標記均重用 TypedArray，避免每次展開建立物件。成本為路徑長度 / 速限 × 壅塞係數，壅塞速度比按 0.1 分級、最低 0.1；換道額外成本 2 秒。等成本比較採 1e-8 秒浮點容差並优先展開接近目的地的狀態，避免幾何取整誤差造成大量平手展開。使用直線距離 / 全網最高速限，以及四個路網極點的自由流最短距離下界（ALT），保持 admissible；壅塞加重不破壞下界。

多車道以 0、2/3、0.81、0.95、1 長度比例建立狀態，無相鄰同向車道時僅保留 0 與 1：最後三分之一才能向相鄰同向車道變換，變換有前進距離並使用平滑橫移，不會從路尾跳回路頭。單行道、轉向車道與禁止左轉沿用車道圖；無可用連接就回傳無路徑。出發點使用獨立虛擬節點，允許繞完整街區後回到同一路段、抵達出發點後方的位置。

步行使用一般道路兩側的獨立雙向路網，單行道與汽車禁左不限制行人；高速公路及匝道完全不生成步行連接，碎石路用路肩。曲線、高程、橋面來自同一道路取樣，連接只在真正共用的節點建立；不同高度／斷開的道路不會憑距離相近相連。步行包含住宅／目的地前緣到人行路徑的短接駁，汽車行程從道路的出入口位置開始／結束。

建築只連到前緣可達範圍中最近的一条地面道路。64 m 空間索引快取道路輪廓和接入點；位置未靠道路時回報無路，不尋找另一個看似接近但不連通的路網。純 `between()` 另接受指定車道位置，供後續高速公路出入口與現有車輛重新尋路使用。

`find()` 最多快取 4096 條成功／失敗路徑，30 財政日到期；路網 revision 變化（含改型、拆除、禁左）重建衍生圖及清除快取，壅塞分級變更清除路徑快取。單次最多探索 20000 個狀態，Worker 每 tick 最多处理 24 個居民請求。`RoutePlanner` 保留每人的原始 Journey，準備路徑但不代替實際移動；無路時回報 blocked，讓行程在稍後重試。M2-10 才會消費已規劃路徑並移動。

`RouteLeg` 包含 lane / junction / laneChange / walk / access。一般車道腿共用原始 points，以 startDistance 表示起點偏移；取樣必須使用 startDistance + 在本腿的前進距離。路口腿帶 node、fromLane / toLane，供交通系統處理號誌與衝突；換道腿保留兩條相鄰車道。道路 revision 寫入 Route，消費端可拒絕舊路。

驗證：單行道與人行雙向、單行環路、不同工作目的地、禁左、失敗快取及到期、道路刪除與斷路、高速公路步行禁止、相鄰換道、壅塞成本、每 tick 請求上限。1000 節點 / 1935 路段的網格，JIT 與前緣索引暖機後，40 次未快取 A* 的本機 p95 約 0.86 ms；圖的預先建立成本不計入單次查詢，並非手機實測。
