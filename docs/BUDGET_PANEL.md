# 財政面板（M1-23）

工具列「財政」開啟可捲動的原生對話框。分區稅率、部門預算、每週收支明細與貸款分別為可展開區塊，滑桿支援觸控及鍵盤。百分比上限先取整數，避免 29% 變成 28.999999999999996% 而無法選取最高值。

明細讀取 Worker 最近一次結算的各分區稅收、各部門維護、貸款本金與利息；並非預估數值，未结算時為零。借款、還款與滑桿等待 Worker 確認後更新。稅率範圍 1～29%，MS3 前高低密度連動；MS1 前預算鎖定，沙盒全部解鎖。一般模式的人口里程碑進度仍依 M4-09 後續任務，這張卡不新增解鎖系統。

驗收使用真實道路／住宅與 Worker，將住宅稅率从 1% 改至 20%，各等待一週，確認住宅稅收提高且住宅需求下降。既有借款、分期與提前清償流程另保留三裝置回歸。
