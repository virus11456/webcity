# M3-03 水面 Shader

水面現在使用兩層原創法線貼圖（8 m 與 40 m）向下游流動；河道座標由 Worker／存檔 river 中線提供，因此彎河的波紋沿河道而非固定世界方向移動。法線及高度資料只在載入／變更時生成或上傳，每幀只更新時間 uniform。

## 外觀

- 深度仍與地形三角形精確對應，淺水較透明、深水較深藍。
- 菲涅耳依視線與擾動法線計算；俯視可見河床，低角度提高天空反射和不透明度。這是天空色近似反射，沒有額外鏡面場景渲染成本。
- 0.8 m 以內的岸邊水深產生不規則泡沫，受移動法線雜訊影響。乾地 discard 避免水面覆蓋陸地。
- 水污染取 Worker 的 300×300 `waterPollution` 場，依 0–100 映射至 ART 褐色，保留深度與反射。`ready` 還原存檔污染；後續 fields 事件增量更新，不由 UI 改變模擬。
- 沿用 MeshStandardMaterial、太陽反光、CSM、霧和資訊圖層。法線在 view-space 正確替換，避免鏡頭旋轉使光照方向錯誤。

原創週期法線 128² 約 85 KiB（含 mipmaps）、污染貼圖 90 KB、河道指引約 1.5 KB；與既有地形高度貼圖共用一次水面 draw call。400 秒相位循環對兩層 UV 都回到整數週期，不在時間折返時跳動。暫停遊戲仍有環境水波；切至背景頁沿用 renderer 暫停。

數值在 `data/water.ts`，污染色在 palette；不新增 runtime 依賴、存檔欄位或平衡數值。

## 驗證

- 單元：法線可重現、單位向量、載入河流與污染資料、污染 clamp、事件輸入不被修改、逐幀不重傳污染貼圖、GPU 清理。
- 三裝置：從真實 IndexedDB 存檔載入曲線河道／淺岸／上下游不同污染場，驗證水波持續動畫並檢查斜視反射、泡沫與污染界線截圖；手機含橫式。
- 既有排污模擬測試與完整回歸檢查水污染權威資料；Shader 只讀取它的結果。

測試用存檔的上下游污染場是控制變因的視覺 fixture，不是新增遊戲場景；正式遊戲仍由排污與擴散系統產生污染。裝置截圖為 Chrome viewport 模擬。

驗證截圖隱藏 debug 與輔助面板，並直接讀取畫面像素確認上游偏藍、下游偏褐。完整單元測試使用單一 worker；此機偶有既有交通效能與 5 秒測試逾時，未改動交通門檻，完整回歸以 15 秒單測逾時再驗證。
