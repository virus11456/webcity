# M3-19 即時畫質設定

主選單與暫停選單共用自動／低／中／高畫質，新增陰影、後製、移軸開關與樹密度 0–100%。日夜保留既有開關。所有設定保存到 preferences，舊存檔補預設值；在城市中切換不重新載入、不改 Worker 世界。

個別設定是畫質上限內的選擇：低畫質不建立陰影或後製，樹密度乘 0.5；中／高保留原單張 1024／三層 CSM 2048 陰影及原後製分級。移軸關閉只停兩個景深 pass，後製關閉則釋放整個 composer。阴影切換釋放舊 light／CSM 並重新安裝材質 hook，樹木以既有分幀批次重建。畫質另限制可見車輛 300／1000／3000，保留完整權威行程與插值位置。

自動畫質保持首次五秒平均低於 30 FPS 直接降低。完成啟動後，連續兩個十秒視窗低於 30 FPS 才再降一級，高→中→低；不自動升級、不反覆抖動。背景／context lost 清除取樣，手動級別完全略過。降級透過 game callback 交給 UI 通知，不由 render import UI；偏好仍保存 auto。單純調音量或日夜不重置已降級的實際畫質。

瀏覽器測試實際切換陰影／後製／移軸、樹木歸零與恢復、三種畫質、日夜，檢查 timeOrigin 不變。自動降級測試加速 RAF 時戳輸入，驗證真實 sampler→renderer→通知完整路徑，並非裝置 FPS 量測；單元測試覆蓋連續慢窗、恢復、背景與手動模式。裝置截圖為 Chrome iPhone／iPad viewport 與觸控模擬。

驗證：930 項單元測試、9 項三裝置畫質／特效／音樂 E2E、lint／typecheck／build 通過。四張設定面板截圖已檢視。
