# 建造復原（M4-18）

底部「復原建造」顯示紀錄筆數、上一筆種類與目前可退金額；直接點按撤銷。遊戲畫布取得焦點時可用 Ctrl+Z 或 macOS Cmd+Z，長按不連續觸發；輸入欄位、對話框與其他瀏覽器快捷鍵保留原行為。

本次城市工作階段保存最近十筆成功、確實改變世界的建造動作：道路、道路升級／反向、分區塗抹／清除、設施、整筆植樹、電線、水管（含整批沿路鋪管）、沙盒地形與災後重建。失敗或無變化不占紀錄，單筆多物件一次復原。人口成長不是玩家建造紀錄。交通路線與班次、政策、財政、購地及拆除不屬於此建造堆疊。

費用由 Worker 原始成功結果記錄，非 UI 提供。建造後未滿七個完整遊戲日退回實付建造費；第七日起仍可復原，但不退款。沙盒與免費劃區不產生錢。復原道路升級一併還原原工程付款年齡與金額，避免再拆除時重複退費。

只儲存受影響物件的前後差異及稀疏高度修改，不還原整個城市時間。時鐘、稅收、貸款、里程碑、歷史統計、市民生命與正在進行的旅程均不倒轉；道路、服務與供應依復原後的世界重新計算。道路分割會還原原路段及連接；分區依當前建築占用重算，撤銷分區後已成長的房屋循既有重新劃區拆除流程。道路拓寬所拆除的住宅恢復為空屋，已搬離市民不會復活或瞬移回來。

所有反向修改先完整驗證：建設已被拆除、更動，或新建築占用了待還原地形時不動世界、不退款，提示並略過失效紀錄，下一次可試前一筆。保留遞增 ID，不回收成舊 ID 給新物件。

紀錄僅在記憶體中，不寫入存檔；保存城市仍正常，載入或重啟後從零筆開始，避免對舊工作階段重複退款。按鈕提示有說明。沒有 redo、批次時間倒帶或額外套件。
