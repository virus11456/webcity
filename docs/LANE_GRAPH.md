# 車道圖（M2-06）

`world/LaneGraph` 從權威道路與路口資料產生有向車道，不在存檔重複保存。Simulation 初始化時重建，之後每次 roadsChanged 都同步。每次先掃描路網比對幾何與節點簽章，只重新產生變動路段及受影響路口；其餘 Lane 與連接物件保留，無變更時 revision 不增加。路網版本供後續尋路快取失效使用。

車道 ID 為路段 ID／方向／車道索引。索引 0 是行車方向內側（單行道為左側）；最大索引為外側。內側可左轉、外側可右轉，每條車道可直行。單車道同時允許三種轉向。直行依新舊車道數比例配對，縮減車道時允許合流。禁止左轉會移除全部左轉連接。不同高度道路只有共用節點才可連接，單行道不生成逆向車道，不允許 U 轉。

車道端點裁在道路畫面使用的同一個路口邊界，轉向連接採三次貝茲平滑路徑。直行角容差 ±30°；150° 以上視為 U 轉；轉彎連接速限最高 8 m/s。相鄰同向車道可透過 adjacent 查詢，後續換道系統控制是否允許實際換道。此卡不產生可見車輛。

`connections(laneId)` 是該車道可通往的下一車道，含路口 ID、轉向、路徑、長度與速限；`lanePointAt` 以距離二分搜尋路徑位置。M2-09 尋路與 M2-10 車流會使用這些資料。
