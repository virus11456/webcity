# 行政區（M4-04）

從建造工具列選「行政區」，新增後自動命名，可輸入名稱重新命名。小／大筆刷半徑為 32／96 m，單指或滑鼠拖曳，放開後套用；雙指接管鏡頭會取消整筆，避免誤塗。橡皮擦使用目前筆刷大小。刪除行政區只清除區界，不拆除建築。

區界採 16 m 格網，僅涵蓋已購地塊。每格只能屬於一區，塗上另一區時轉移所有權。最多 64 區、名稱 1–32 字元，每筆最多 128 個取樣點，取樣點間連續插值。一般模式於 MS2 解鎖，沙盒直接開放，畫區不收費。小／大筆刷和上限集中在 `src/data/districts.ts`。

面板顯示區內建築中心點所屬的人口、入住戶數、已就業人數／職位總量、建築數及面積。資料來自 Worker 權威建築資料，劃區、拆建與每日人口變動後更新。工業區的「就業」是該區工作場所的員工，不是住在該區的勞動人口。

選擇行政區工具時顯示彩色範圍與區名；離開工具後，鏡頭距離達 500 m 仍顯示區名。格網頂點隨地形取樣，區名使用原創文字材質。名稱、區界與 ID 隨城市存檔保存，載入拒絕重複 ID、非法格子與重疊區界。舊版空行政區存檔相容。

政策及工業特化由 M4-05、M4-06 接續。本卡不改變建築分區種類，亦未宣稱 iOS Safari 實機或大城市壓力驗證。
