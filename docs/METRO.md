# M4-02 地鐵

地鐵工具先建造沿路車站，再回到「地鐵」點選至少兩座站體，按「鋪軌並開通環線」。確認前顯示造價，Worker 檢查解鎖、車站、土地及資金，成功後才一次扣款與建立地下軌道。兩站往返，三站以上按點選順序閉合循環；每線一列車，無共軌、轉乘、分岔或獨立軌道編輯。車站 $9,000／$360 每週，軌道 $60 每 8 m，每車 180 席、$120 每週、票價 $4。

列車的真實位置與接駁行人共用 TrafficSystem 更新及儲存，地下軌道不使用汽車車道或地面號誌。居民從家步行進站、候車、搭車，抵達後步行到工作地點；保留原本的個人與行程。車站停用、拆除或道路斷開時暫停路線，乘客在當前位置重新尋路；刪線保留已收票款。沿用公車 600 位同時接駁乘客上限，其餘居民採一般交通方式。

地下工具將地面變透明、顯示軌道與列車；退出工具恢復地表，地下列車仍會運行。已存在的 M3 原創地鐵／車站模型直接使用，沒有外部素材或新 runtime 套件。建站仍使用公共服務放置工具，雙指取消不會提交指令。
